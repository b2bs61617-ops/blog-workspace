# KO1KEYZ「BLACK ANGEL」の歌割りは？6人パート！

<!-- wp:paragraph -->
<p>KO1KEYZ(コイキーズ)が2026年8月に開幕した「1ST FAN MEETING」で披露した楽曲のひとつが「BLACK ANGEL -KO1KEYZ 6人ver.-」です。<br>
「BLACK ANGEL」はもともと『PRODUCE 101 JAPAN 新世界(日プ新世界)』のコンセプト評価で披露されたダーク&セクシーな世界観の楽曲で、<strong>作詞をHiyori Naraさん、作曲・編曲をMADEWELL(AVEC)さん・zeewoo(GALACTIKA*)さんらが手がけ、披露したチームが1位を獲得した曲</strong>です。<br>
ファンミではRYOGA・RYUJI・SHINHAENG・SIYOUNG・YUKI・YURAの6人による「6人ver.」として披露されました。この記事では、ファンの聞き取りをもとにした歌割り(パート分け)を、メンバーの絵文字ではなくローマ字表記の名前に置き換えて一覧にまとめました。<br>
なお公式音源・歌詞はまだ発表されていないため、パートや歌詞はファンによる耳コピをもとにした暫定版として読んでください。</p>

<h2 class="wp-block-heading">「BLACK ANGEL」はどんな曲?日プ新世界のコンセプト評価曲</h2>
<!-- /wp:heading -->

<!-- wp:html -->
<div style="border:1px solid #ddd9d3;border-left:4px solid #8a8378;border-radius:4px;padding:10px 16px;margin:0 0 16px 0;background:#f7f6f4;">
<p style="margin:0;"><strong>曲名:</strong>BLACK ANGEL -KO1KEYZ 6人ver.-</p>
<p style="margin:4px 0 0 0;"><strong>原曲:</strong>『PRODUCE 101 JAPAN 新世界』コンセプト評価の楽曲(禁断の物語をダーク&セクシーに描いた1曲、披露チームが1位を獲得)</p>
<p style="margin:4px 0 0 0;"><strong>作詞・作曲・編曲:</strong>作詞=Hiyori Nara/作曲・編曲=MADEWELL(AVEC)・zeewoo(GALACTIKA*)・LEY(AVEC)・Heeyeon(AVEC)・Z-UK(AVEC)</p>
<p style="margin:4px 0 0 0;"><strong>KO1KEYZ 6人ver.の披露メンバー:</strong>RYOGA・RYUJI・SHINHAENG・SIYOUNG・YUKI・YURA</p>
<p style="margin:4px 0 0 0;"><strong>披露場所:</strong>2026年8月21日開幕「2026 KO1KEYZ 1ST FAN MEETING」(東京・兵庫)</p>
</div>
<!-- /wp:html -->

<!-- wp:paragraph -->
<p>「BLACK ANGEL」は、『PRODUCE 101 JAPAN 新世界』のコンセプト評価で披露された楽曲のひとつです。<br>
コンセプト評価は、第2回順位発表式を勝ち抜いた35人の練習生が7人ずつ5チームに分かれ、それぞれ異なるジャンルのオリジナル楽曲でパフォーマンスを競う課題で、「BLACK ANGEL」を披露したチームはこの回で1位を獲得しています。<br>
作詞はHiyori Naraさん、作曲・編曲はMADEWELL(AVEC)さん・zeewoo(GALACTIKA*)さんらが手がけ、禁断の恋を描いたダークかつセクシーな世界観が高く評価された1曲でした。<br>
デビュー前の番組時代を知るファンにとっては、当時1位を獲得した思い入れの強い楽曲のひとつで、ファンミではRYOGA・RYUJI・SHINHAENG・SIYOUNG・YUKI・YURAの6人による「KO1KEYZ 6人ver.」として新たに歌い直されました。<br>
同じファンミでは、もう1つのコンセプト評価曲「Neko」も披露されており、番組時代の楽曲がKO1KEYZとして再演される流れは今回のファンミの見どころのひとつになっています。</p>

<p>1番と大サビでは「舞い落ちた翼もう飛べない」「潤される程 渇いてくdesire」「どこまでも行こう 君が望むなら」「Sol愛」という同じ流れが繰り返されますが、担当メンバーはそれぞれ入れ替わっているのが特徴です。<br>
公式音源が出れば、ユニゾンの範囲や細かい歌い出しがもう少しはっきりすると思われます。</p>
<!-- /wp:paragraph -->

<!-- wp:heading -->
<h2 class="wp-block-heading">歌割りから見える注目ポイント</h2>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>6人の歌割りを見ていくと、まず<strong>「舞い落ちた翼もう飛べない → 潤される程 渇いてくdesire → どこまでも行こう 君が望むなら → Sol愛」という1番サビの流れが、大サビでは担当がそっくり入れ替わって再登場</strong>する構成になっています。<br>
1番サビはRYUJI→SIYOUNG→RYOGA→YURA→SHINHAENGの順、大サビはRYOGA→SIYOUNG→RYUJI→SHINHAENG→SIYOUNGの順と、同じ旋律を違う声で聴かせる作りです。</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>間奏で挟まる<strong>「Pray / 闇に染めてこのまま2人 / Sol愛」は、1回目がSHINHAENG、2回目がYURA</strong>と担当します。<br>
プリコーラスの<strong>「君に堕ちて行くfalling / 何度も求め続けるpain / Settle me down, so settle me down / 分かっているのに wanna love you」も、1番と2番で歌う4人がまるごと入れ替わる</strong>珍しい構成です(1番:YURA→RYUJI→YUKI→SIYOUNG、2番:SIYOUNG→RYOGA→YUKI→SHINHAENG)。<br>
この曲で唯一の掛け合いが<strong>「全てを捧げよう」のRYOGA・YUKI</strong>で、ダークな世界観の中でも2人の声が重なる印象的な一節になっています。</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>6人それぞれの持ちパート数を見ると、YUKI・SIYOUNG・RYUJI・RYOGA・SHINHAENG・YURAといずれも複数回登場しており、偏りの少ないバランス型の歌割りといえます。<br>

<h2 class="wp-block-heading">「BLACK ANGEL」の歌詞に込められた世界観</h2>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>「BLACK ANGEL」は、タイトルどおり<strong>禁断の恋・逃れられない愛</strong>をテーマにした、ダークかつセクシーな世界観の楽曲です。<br>
「白い羽の裏 隠してたemotion」「翼のない君」「舞い落ちた翼もう飛べない」といった、天使をモチーフにした比喩が繰り返し登場し、堕ちていく恋そのものを"翼を失う"ことにたとえています。<br>
「もしもこの愛が罪なら裁かれてもいい」「愛に溺れて 運命の果てまででも」というサビの歌詞からは、後戻りできない感情に飲み込まれていく様子が伝わってきます。</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>「Run Again」が前向きな未来を歌う爽やかな楽曲だったのに対し、「BLACK ANGEL」はその対極にある、大人びた退廃的な魅力を見せる楽曲です。<br>
同じ12人(6人)がまったく違う世界観の曲を歌いこなす幅の広さも、この曲がコンセプト評価で1位を獲得した理由のひとつだったと考えられます。<br>
ファンミでの「KO1KEYZ 6人ver.」は、番組時代のこの評価をデビュー後のステージでもう一度見せる、思い入れの強いパフォーマンスになりました。</p>
