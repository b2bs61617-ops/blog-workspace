# トラジャ7人のピアスの数と位置を徹底比較!

調べてみると、<strong>川島如恵留は耳だけで7個、さらにへそにも1個</strong>という圧倒的な本数である一方、<strong>中村海人はメンバーで唯一ピアスホールを開けていない</strong>という対照的な結果になりました。<br>

## 川島如恵留はメンバー最多、耳に7個+へそピ

<div style="border:1px solid #cddbe9;border-left:4px solid #6a8caf;border-radius:4px;padding:10px 16px;margin:0 0 16px 0;background:#eef3f8;">
<p style="margin:0;"><strong>本数・位置:</strong>耳たぶに計7個(左耳4・右耳3)、さらにへそにも1個</p>
</div>

川島如恵留は7人の中でもっともピアスホールの数が多いメンバーで、耳だけで計7個、さらにへそにも1個開けています。<br>
ファンミーティングのMCトークで本人が明かしたところによると、耳の7個はTravis Japanのメンバー7人分にちなんだもので、左耳に4個・右耳に3個という内訳で、それぞれのメンバーの誕生石をあしらったピアスをつけているとのことです。<br>
「7個の方が縁起がいいから」と笑いながら語っていたこともあり、メンバー想いの深さがうかがえるエピソードとしてファンの間で長く語り継がれています。<br>
なお軟骨(ヘリックスなど)には開けておらず、7個はすべて耳たぶに集中しているのも特徴です。

さらに、Travis Japanとしてのデビューを機に8個目のピアスホールをへそに開けたことも話題になりました。<br>
以降のツアーや生配信でも衣装の隙間からへそピアスがのぞく場面がたびたび確認されており、直近のコンサートでも健在であることがうかがえます。

普段はシルバーやゴールドのシンプルなフープを1〜2個だけ着けるスタイルが多く、7個をフルに見せる機会はそう多くありません。<br>
鍵モチーフのチャームが揺れるデザインを選ぶこともあり、MC業や生配信の際はピアスを外していることも多いため、「今日はピアスしてる、レアい」といった声が上がるのもこのメンバーらしいところです。<br>
以前は「Nintendo Switch 2」関連のプレイ動画で着けていたピアスがTIFFANY&CO.の「ロック」コレクションではないかとファンの間で特定され、大きな話題になったこともありました。<br>

## 中村海人はピアスホールがない唯一のメンバー

<div style="border:1px solid #cddbe9;border-left:4px solid #6a8caf;border-radius:4px;padding:10px 16px;margin:0 0 16px 0;background:#eef3f8;">
<p style="margin:0;"><strong>本数・位置:</strong>0個(ピアスホールなし)</p>
</div>

7人の中で唯一、ピアスホールを開けていないのが中村海人です。<br>
本人はライブ配信で「ピアスは怖いから絶対あけない」「チャラくなっちゃうのが嫌」と繰り返し話しており、揺るがないスタンスであることがうかがえます。<br>
女性へのプレゼントなら「ピアス。穴が開いていなかったら開けてもらう」と語ったこともあり、自分では開けない一方でピアスそのものが嫌いというわけではなさそうです。

耳元を華やかにしたいときは、穴を開けずに装着できるイヤーカフを愛用しています。<br>
雑誌「美的」のソロ表紙でも、ピアスの代わりにイヤーカフを着けたスタイリングが披露され、「ピアスをしないうみくんのイヤーカフの破壊力」とファンの間で好評でした。<br>
ドラマ出演時に共演者が中村のメンバーカラーである緑のイヤーカフを片耳だけ着けていたことがあり、これは中村不在の代役としての演出だったのではとファンの間で推測されていました。

## 松倉海斗は元太と一緒に留学先で開けた

<div style="border:1px solid #cddbe9;border-left:4px solid #6a8caf;border-radius:4px;padding:10px 16px;margin:0 0 16px 0;background:#eef3f8;">
<p style="margin:0;"><strong>本数・位置:</strong>非公表(複数のハイブランドピアスを片耳中心に着用)</p>
</div>

松倉海斗のファーストピアスは、アメリカ留学中に松田元太と2人でそろって開けたというエピソードで知られています。<br>
バラエティ番組「踊る!さんま御殿!!」で本人たちが語ったところによると、現地の病院で「3・2・1・go」のかけ声のはずが実際には2カウントで開けられてしまい、費用は300〜400ドルほどだったそうです。<br>
正確な本数は公式に発表されていませんが、TiffanyのT One フープピアス(ホワイトゴールド)やクロムハーツのクロスボールスタッドなど、複数の高価なピアスを日によって使い分けている様子がSNSでたびたび確認できます。

過去には収録の合間にピアスを紛失してしまい、「去年も1セットなくした」とファンの間で心配されたこともありました。<br>
着用ブランドの詳しい特定については、[松倉海斗のピアスをクロムハーツと特定した記事](https://chomoand-0.com/?p=612)でさらに詳しく調査しています。

## 松田元太も松倉と同時に開けた両耳派

<div style="border:1px solid #cddbe9;border-left:4px solid #6a8caf;border-radius:4px;padding:10px 16px;margin:0 0 16px 0;background:#eef3f8;">
<p style="margin:0;"><strong>本数・位置:</strong>非公表(両耳に着けている姿が多い)</p>
</div>

松田元太も、前述の松倉海斗との「ファーストピアスを2人で開けた」エピソードの当事者です。<br>
「踊る!さんま御殿!!」では、留学中にアメリカの病院でピアスを開けた話が「松松ピアス」として盛り上がり、今でもファンの間で語り継がれるエピソードのひとつになっています。<br>
普段は両耳にピアスを着けている姿がよく見られ、ファン考案の等身大ぬいぐるみの特徴にも「ピアス両耳あり」という項目が挙がるほど定着したイメージです。

一方で、ナチュラルメイクの日や役柄によってはピアスを外して登場することもあり、「ピアス無しの元太くんも新鮮」と話題になる場面もあります。<br>
黒のスタッドタイプやフープタイプなど、その日の衣装に合わせてデザインを変える柔軟さもファンから支持されているポイントです。

## 七五三掛龍也は片耳に2つ重ねづけすることも

<div style="border:1px solid #cddbe9;border-left:4px solid #6a8caf;border-radius:4px;padding:10px 16px;margin:0 0 16px 0;background:#eef3f8;">
<p style="margin:0;"><strong>本数・位置:</strong>非公表(左耳中心、片耳に2つ着ける日もあり)</p>
</div>

七五三掛龍也は、ジュエリー選びのセンスに定評があるメンバーです。<br>
イベントレポートでは「左耳のピアスはカルティエ ジュストアンクルのピンクゴールド」と具体的なアイテムまで報告されるなど、日替わりで高級ブランドのピアスを着けこなしている様子がうかがえます。<br>
ある日はCHANELのピアスを片耳に2つ重ねづけしており、「しめちゃんは片耳に2つ開いてるの?」とファンの間で本数について話題になったこともありました。

過去の写真では、以前開けていたピアスホールの一部が現在は塞がっているとの声もあり、これまでに複数のホールを経験してきたことがうかがえます。<br>
左耳のほくろとピアスが並ぶ位置関係も「カシオペア座みたい」とファンから愛されているポイントのひとつです。

## 吉澤閑也は2024年2月にピアスデビュー

<div style="border:1px solid #cddbe9;border-left:4px solid #6a8caf;border-radius:4px;padding:10px 16px;margin:0 0 16px 0;background:#eef3f8;">
<p style="margin:0;"><strong>本数・位置:</strong>1個(主に片耳)</p>
</div>

吉澤閑也は、メンバーの中でも比較的最近ピアスを開けたメンバーです。<br>
X上では「本日、2月11日は吉澤閑也ピアスホール開通記念日です」といった投稿が毎年見られ、2024年2月11日ごろにピアスデビューしたことがうかがえます。<br>
それ以前の番組映像には「ピアスの開いていない吉澤閑也くん」の姿も残っており、開通前後の変化がファンの間で話題になっていました。

現在は基本的に1つの穴に大きめのフープを着けるスタイルが定番で、片方だけ外れていたり紛失してしまったりすることが多く、そのたびに「ピアス見つかった?」とファンの間で心配されるのもお馴染みの光景です。<br>
FENDIの「FF」ピアスなど、ブランドが判明した着用アイテムも複数報告されています。

## 宮近海斗は川島に次ぐ5個

<div style="border:1px solid #cddbe9;border-left:4px solid #6a8caf;border-radius:4px;padding:10px 16px;margin:0 0 16px 0;background:#eef3f8;">
<p style="margin:0;"><strong>本数・位置:</strong>合計5個(右耳3・左耳2)</p>
</div>

7人の中でも川島如恵留に次いでピアスの本数が多いのが宮近海斗です。<br>
内訳は右耳に3つ(耳たぶ2つ・軟骨のヘリックス1つ)、左耳に2つ(耳たぶ1つ・オービタル1つ)というバランスで、開けた時期は在学していた堀越学園を卒業した後だとされています。<br>
在学中は校則でピアスが禁止されていたため我慢し、卒業後にまとめて複数のホールを開けたという経緯のようです。

耳たぶ部分はCARTIERのゴールドフープ、軟骨部分はANATOMETALのクラスタースタッドの可能性があるとみられており、「ピアスの数と位置を確定、ほぼ本人確定」とファンが冗談まじりに"鑑識"と称するほど、ホールの位置がよく知られています。<br>

## まとめ

Travis Japan7人のピアス事情を比較すると、次のような違いが見えてきました。

- 川島:耳に計7個(左耳4・右耳3)+へそピ1個、メンバー最多
- 中村:0個(唯一の未開通、イヤーカフで代用)
- 松倉:非公表、片耳中心に高価なピアスを日替わりで着用
- 松田:非公表、両耳派で日によって外すことも
- 七五三掛:非公表、左耳中心で片耳に2つ重ねる日もあり
- 吉澤:1個、主に片耳
- 宮近:5個(右耳3・左耳2)、川島に次ぐ本数

同じグループでも耳元のスタイルはメンバーごとにこれだけ違い、それぞれのファッションセンスやエピソードが反映されているのが分かります。<br>
ライブや番組を見るときは、ぜひメンバーそれぞれの耳元にも注目してみてください!
