2026年9月29日(火)21時、フジテレビ系で映画『マッチング』(2024年公開)が地上波初放送されます。
続編『マッチング TRUE LOVE』が9月25日に公開されたタイミングでの放送ということもあり、「最後の意味がわからなかった」「結局犯人は誰？」という声が一気に増えています。

※この記事は映画『マッチング』の結末までのネタバレを含みます。

結論から言うと、事件の犯人は1人ではありません。
輪花の周りの人を殺したのは影山(金子ノブアキ)、アプリ婚カップルの連続殺人は吐夢(佐久間大介)の犯行だと示されています。
そしてラストの衝撃は、恋人同士になった輪花と吐夢が、実は父親が同じ「異母姉弟」だったという点です。

この記事では、Yahoo!知恵袋などに寄せられている疑問に答える形で、真相・人物関係・ラストシーンの意味を整理していきます。

ウエディングプランナーの輪花が、マッチングアプリで出会った吐夢に執着され、同時期に起きていた「アプリ婚連続殺人事件」に巻き込まれていくサスペンス・スリラーです。
アプリ運営会社のプログラマー・影山が輪花の相談役として寄り添う、という三角関係のような構図で物語が進みます。

映画マッチングの最後の意味は？犯人は結局誰？

Yahoo!知恵袋には、公開直後から「最後がどういうことかわからなかった」「結局犯人はストーカーの人(佐久間)ですか？」という質問が寄せられていました。
混乱しやすいのは、別々の目的を持った犯人が同時に動いていたからです。

輪花の身近な人を殺したのは影山

中盤まで「怪しいのは吐夢」と思わせておいて、輪花を支えていた影山こそが犯人でした。
影山は逮捕後、輪花の同僚・尚美と、片岡夫妻の殺害を認めています。

ただし影山が認めたのは「この2件だけ」。
その後に新たなアプリ婚殺人が起き、連続殺人の大部分は影山の犯行ではないことがはっきりします。

アプリ婚連続殺人の犯人は吐夢

ラストシーンで、吐夢が公衆トイレで血の付いた刃物を洗い流す姿が映ります。
これにより、ストーカーでありながら終盤では輪花を守る側に回った吐夢こそが、アプリで結ばれた夫婦を狙う連続殺人犯だったことが示唆されます。

映画では吐夢の犯行を直接的には描かず、最後の数カットで観客に気付かせる作りになっているため、「結局どっち？」と感じた人が多かったのも無理はありません。

影山の正体と動機は？

影山剛の正体は、輪花の父・芳樹の不倫相手だった節子(斉藤由貴)の長男です。

25年前、芳樹と節子は不倫関係にあり、別れを切り出された節子は芳樹を刺して服役しました。
母が捨てられ心を壊していく姿を見てきた影山は、芳樹とその娘・輪花への復讐のためにアプリ運営会社の立場を利用して輪花に近づいたとされています。
「母さんのために」という執着、つまり母にもう一度愛されたいという歪んだ思いが、彼を動かしていたと読み取れます。

ちなみに輪花の父・芳樹は、節子からの電話で精神的に追い詰められた末、橋で首をつった状態で見つかり、自殺と判断されています。

吐夢の正体は？輪花との本当の関係

吐夢は、節子と芳樹の間に生まれた子どもです。
生まれてすぐコインロッカーに捨てられ、キリスト教系の養護施設で育ちました。

ここから人物関係を整理すると、次のようになります。

関係つながり
吐夢と影山母(節子)が同じ異父兄弟
吐夢と輪花父(芳樹)が同じ異母姉弟
節子と輪花の母・美知子節子が美知子を25年間監禁していた

輪花が幼い頃に失踪したと思われていた母・美知子は、実は出所後の節子に誘拐され、25年間も監禁されていました。
終盤、輪花と吐夢が湖畔の家にたどり着き、車いすの女性が美知子だと判明するシーンは、この物語の「もう一つの事件」の答えです。

吐夢が連続殺人をした理由は？

映画の中では動機がはっきり語られませんが、原作小説や考察では「真実の愛があるのかを確かめるため」だと解釈されています。

吐夢はマッチングアプリで結婚した夫婦に「愛があるのか」を試し、愛がないと判断した相手を殺していた、という見方です。
小説版では、被害者の2人に「どちらが死ぬべきか」を選ばせるルールを課していたことも描かれています。
被害者の顔に残された十字の傷は、彼が育った施設の宗教観、聖書の「愛」の概念とつながっていると考えられます。

親に捨てられ、一度も愛された経験がない吐夢にとって、「本物の愛」と「家族」は何よりも欲しいものでした。
その欲しいものを持っていそうな夫婦を「試す」という行動が、歪んだ形で殺人に結びついたと読むと、彼の不気味さの正体が見えてきます。

ラストシーンの吐夢の笑みはどういう意味？

ラストは、輪花と吐夢が水族館でミズクラゲを見ながら手をつなぐシーンで終わります。
輪花は吐夢が自分の弟だとは知らないまま、彼に心を許しています。
一方の吐夢は、最後にかすかな笑みを浮かべます。

この「最後の1秒」について、考察では主に次のような解釈が出ています。

解釈①:ずっと欲しかった「愛」と「家族」を同時に手に入れた

知恵袋のベストアンサーでも挙げられていたのがこの解釈です。
吐夢は輪花が姉だと知ったうえで、恋人としての愛と、家族としての愛の両方を手に入れた。
それが「禁断の愛」だと分かっていながら、ほくそ笑んだという読み方です。

解釈②:輪花もいつか「試される」側になる

吐夢が愛を試して殺してきた人物だと考えると、輪花もいつか同じ「試験」にかけられるのでは、という怖さが残ります。
笑みを「幸せ」ではなく「次の始まり」と読むと、一気にホラーとしての後味が強くなります。

解釈③:無垢さと恐ろしさが同居した「人間らしさ」

愛し返されることを想定していなかった吐夢が、初めて輪花から愛を受け取った瞬間の、純粋な喜びの表情だという見方もあります。
純粋であるほど怖い、というのが佐久間大介さんの演技の評価が高い理由の一つでしょう。

見逃しがちな伏線:四つ葉のクローバーとミズクラゲ

ラストの意味を読み解くカギになるのが、何度も登場するモチーフです。

  • 四つ葉のクローバー:コインロッカーに捨てられた吐夢に残されていたロケットペンダントの中身。節子が身につけていたもので、吐夢と母をつなぐ唯一の手がかりです。
  • ミズクラゲ:ラストで2人が見つめるミズクラゲは、模様が四つ葉のクローバーのように見えます。吐夢の出生の秘密=輪花との血のつながりを暗示する映像だと考えられています。

「幸福の象徴」であるはずの四つ葉が、実は2人が決して結ばれてはいけない関係であることを示している、という皮肉な演出です。
地上波で見返すなら、ペンダントとクラゲのシーンに注目すると印象が大きく変わるはずです。

続編『マッチング TRUE LOVE』とのつながりは？

2026年9月25日に公開された続編『マッチング TRUE LOVE』は、前作から2年後が舞台です。
輪花と吐夢は恋人関係を続けていましたが、輪花への脅迫状をきっかけに吐夢が姿を消し、輪花は南の島で行われるマッチングツアーに参加。
孤島で誕生したカップルが次々と殺されるデスゲームのような事件に巻き込まれていきます。

続編では、吐夢がキリスト教系の養護施設「エデン」で育ったことが語られ、前作で謎だった十字の傷の意味も回収されます。
前作ラストの「2人はこのまま一緒にいるのか？」という疑問に、正面から向き合う物語になっているので、今夜の放送で前作を見た人はそのまま劇場へ行くのがおすすめです。

まとめ

  • 輪花の同僚・尚美と片岡夫妻を殺したのは影山(節子の長男、動機は芳樹と輪花への復讐)
  • アプリ婚連続殺人の犯人は吐夢(ラストの凶器を洗うシーンで示唆)
  • 吐夢は芳樹と節子の子で、輪花とは異母姉弟、影山とは異父兄弟
  • ラストの笑みは「愛と家族を同時に手に入れた喜び」とも「輪花も試される側になる不穏さ」とも読める
  • 四つ葉のクローバーとミズクラゲが、2人の血のつながりを暗示する伏線
