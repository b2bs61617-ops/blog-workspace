ネックレスはクロムハーツの「ベビーファット クロス」

ブランド:CHROME HEARTS(クロムハーツ)

モデル:ベビーファット クロス(パヴェダイヤ)とみられる

素材:シルバー

大きさ:縦 約24mm・横 約9mm(同じモデルの例)

ネックレスがいちばん大きく映るのは、26分50秒ごろに松倉海斗さんがカメラに近づいた場面です。
十字の形をアップで見ると、クロムハーツの特徴がそろっていました。

✓ 十字の4本のうでが、ぽってりと丸くて太い

✓ うでのまわりに、ふちどりのような段がある

✓ 十字の上に丸カンがあり、そこにチェーンを通している

✓ 全体が細かくキラキラ光っていて、ダイヤが敷きつめられている

同じクロムハーツの十字でも、「タイニーCHクロス」は先がとがったダガーのような形です。
今回の十字は先が丸くてずんぐりしているので、「ベビーファット」の形にいちばん近いです。

ゴールドではなくシルバー

部屋の照明がオレンジっぽいので、チェーンが少し金色に見える場面もあります。
ただ、白いTシャツや銀色のジッパーと並べると、十字そのものは白っぽい銀色でした。
ベビーファットのダイヤ入りは22Kゴールドもありますが、今回はシルバーとみられます。

値段は？

クロムハーツは、日本の公式サイトで値段を出していません。
海外の中古ショップでは、シルバーのダイヤ入りが約3,900ドルでした。
これはボールチェーン付きの値段です(11月13日に確認)。
22Kゴールドのダイヤ入りは、中古で30万〜40万円ほどで取り引きされています。

ダイヤの量やチェーンの長さで、値段は大きく変わります。
買うときは、クロムハーツの直営店で確かめるのがいちばん確実です。

最近の松倉海斗さんは、ティファニーの「ロック」のネックレスをよく着けていました。
くわしくはティファニーのロックの記事で紹介しています。
誕生日の配信では、十字のネックレスに替えていたのも見どころです。

指輪はエルメスの「シェーヌ・ダンクル・アンシェネ」

ブランド:HERMÈS(エルメス)

モデル:リング《シェーヌ・ダンクル・アンシェネ》PM とみられる

着けていた指:右手の中指

素材:シルバーとみられる(ダイヤなし)

21分50秒ごろ、松倉海斗さんが両手をぎゅっと胸の前でにぎる場面があります。
このとき、右手の中指に鎖の形の指輪がはっきり映りました。

✓ 楕円の輪っかの真ん中に、横に1本の棒が入っている

✓ その輪っかが、指のまわりをぐるっとつながっている

✓ 輪っかの表面はつるんとしていて、ダイヤはない

「シェーヌ・ダンクル」は、船のいかりの鎖をモチーフにしたエルメスの定番デザインです。
輪っかがつながった指輪は「アンシェネ」という名前で、細めのPMサイズとみられます。

シルバー？ピンクゴールド？

同じデザインには、ピンクゴールドやダイヤ入りもあります。
でも、左手の薬指のシルバーの指輪と色を比べると、同じ白っぽい銀色でした。
ネックレスも時計も銀色なので、シルバーでそろえていたとみられます。

ピンクゴールドとダイヤ入りは、11月13日にエルメス公式オンラインストアで確認した値段です。
ピンクゴールドの商品番号はH110025B 00047、はばは0.58cmです。
シルバーは公式で新品の値段が見つからず、中古のお店で9万円台でした。

左手の指輪は？

左手の人差し指には四角い台のついた指輪、薬指には模様の入ったシルバーの指輪をしていました。
どちらも動画の画質ではブランドまで分からなかったので、わかりしだい追記します。

腕時計はいつものカルティエのタンク

14分ごろ、両手を合わせる場面で、左手首に四角い腕時計が映りました。
銀色の角形のケースに、茶色の革ベルトの組み合わせです。

これは、逆引きランキングの動画でも着けていたカルティエの「タンク」とみられます。
