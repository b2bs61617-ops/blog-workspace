# KO1KEYZ「Run Again」の歌割りは？全12人のパート！

<!-- wp:paragraph -->
<p>KO1KEYZ(コイキーズ)が2026年8月に開幕した「1ST FAN MEETING」のアンコールで、メンバー12人がトロッコに乗って披露したのが「Run Again -KO1KEYZ ver.-」です。<br>
この曲はもともと『PRODUCE 101 JAPAN 新世界(日プ新世界)』のファイナルで練習生全員が歌ったスペシャルステージ曲で、<strong>作詞・作曲を手がけたのはJO1の川尻蓮さん</strong>です。<br>
ファンミで披露された「KO1KEYZ ver.」は、この曲を12人でどう歌い分けているのかが見どころ。この記事では、ファンの聞き取りをもとにした歌割り(パート分け)を、メンバーの絵文字ではなくローマ字表記の名前に置き換えて一覧にまとめました。<br>
なお公式音源・歌詞はまだ発表されていないため、パートや歌詞はファンによる耳コピをもとにした暫定版として読んでください。</p>

<!-- wp:heading -->
<h2 class="wp-block-heading">「Run Again」はどんな曲?1ST FAN MEETINGのアンコールで披露</h2>
<!-- /wp:heading -->

<!-- wp:html -->
<div style="border:1px solid #ddd9d3;border-left:4px solid #8a8378;border-radius:4px;padding:10px 16px;margin:0 0 16px 0;background:#f7f6f4;">
<p style="margin:0;"><strong>曲名:</strong>Run Again -KO1KEYZ ver.-</p>
<p style="margin:4px 0 0 0;"><strong>原曲:</strong>『PRODUCE 101 JAPAN 新世界』ファイナルのスペシャルステージ曲(練習生全員で披露)</p>
<p style="margin:4px 0 0 0;"><strong>作詞・作曲:</strong>川尻蓮(JO1)</p>
<p style="margin:4px 0 0 0;"><strong>KO1KEYZ ver.の初披露:</strong>2026年8月21日開幕「2026 KO1KEYZ 1ST FAN MEETING」(東京・兵庫)のアンコール</p>
<p style="margin:4px 0 0 0;"><strong>演出:</strong>メンバーがトロッコで客席をまわり、サイン入りボールを投げ込みながら歌唱。「新世界 -KO1KEYZ ver.-」と続けて披露</p>
</div>
<!-- /wp:html -->

<!-- wp:paragraph -->
<p>「Run Again」は、2026年6月の『PRODUCE 101 JAPAN 新世界』ファイナルで、その時点の練習生全員がスペシャルステージとして歌った楽曲です。<br>
作詞・作曲を担当したのはJO1の川尻蓮さんで、川尻さん本人もファイナル会場に姿を見せ、自身が書いた曲がステージで披露される様子を見届けています。<br>
番組から生まれたKO1KEYZが、デビュー前の初めてのファンミでこの曲を「12人ver.」として歌い直した形で、オーディションの日々を知るファンにとっては特別な意味を持つセットリストになりました。<br>
アンコールではトロッコに乗って客席を回り、サイン入りのボールを投げ込みながら歌うという演出で、「新世界 -KO1KEYZ ver.-」と続けて披露されています。<br>
ファンミ初日の流れは<a href="https://chomoand-1.com/ko1keyz1st-fan-meeting-tokyo-f-11644" target="_blank" rel="noopener">KO1KEYZ 1stファンミ初日のセトリ・座席表・トロッコ演出をまとめた記事</a>でも詳しく紹介しています。</p>

<!-- wp:paragraph -->
<p>ファンの耳コピをもとにした歌割りを眺めると、いくつか特徴が見えてきます。<br>
まず、<strong>12人全員にソロで歌うパートが割り振られている</strong>のがこの曲の大きな特徴です。<br>
特定の何人かに偏らず、Aメロからアウトロまでをリレーのようにつないでいく構成で、原曲が「練習生全員のスペシャルステージ」だったことを踏まえた歌割りになっています。</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>英語詞の<strong>「Cause you'll be nothing / if you forget truly who you are」</strong>というフックは、登場するたびに担当が入れ替わります。<br>
1番プリコーラスと大サビ前はISSA、2番プリコーラスはRYUJI、アウトロはSHINHAENGと、曲の要になるこの一節を4回中2回ISSAが担当している点が目を引きます。<br>
同じく「Take you where the stars shine」も、SHINHAENG・ISSA・SIYOUNGと場面ごとに歌い手が変わります。</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>ラップ調で畳みかける<strong>「Ay run 助走は充分に / run 傷も抱いて行く」はTOWA</strong>が担当し、続く<strong>「この1歩で拓く未来 / 君と僕で創る新世界」はDAIKIとTOWAの2人</strong>で歌われています(耳コピ投稿でも絵文字が2つ並記されていました)。<br>
そのまま<strong>「Just follow me」をKOSUKE</strong>が受けて大サビ前へ流れ込む、この曲の盛り上がりどころです。</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>サビの<strong>「僕らで」は1番サビ・大サビともにKEITO</strong>が歌っていて、短いフレーズながら毎回同じメンバーが担当する数少ない固定パートになっています。<br>
また、曲の入り(1番Aメロの1行目)はYUKI、曲を締める最後の一節<strong>「そばにいるよ」はYURA</strong>と、始まりと終わりで別のメンバーが立っているのも印象的です。<br>
各メンバーの絵文字とカラーの対応は<a href="https://chomoand-1.com/summary-of-ko1keyz-member-emoj-10560" target="_blank" rel="noopener">KO1KEYZメンバー絵文字まとめの記事</a>、カラー一覧は<a href="https://chomoand-1.com/ko1keyz-no-color-10196" target="_blank" rel="noopener">メンバーカラーの記事</a>で確認できます。</p>
<!-- /wp:paragraph -->

<!-- wp:heading -->
<h2 class="wp-block-heading">「Run Again」の歌詞に込められた意味</h2>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>「Run Again」は、タイトルどおり<strong>「何度転んでも、もう一度走り出そう」</strong>というメッセージが軸になった楽曲です。<br>
「また転んだら膝抱えて」「間違いだらけの足跡でも」「遠回りさえ意味に変わる」といったフレーズが並び、うまくいかない時間も含めて前に進む、という前向きなテーマで貫かれています。<br>
オーディションという勝ち負けのある場所を通ってきたKO1KEYZの12人が歌うことで、この歌詞はデビューまでの道のりそのものと重なって聞こえます。</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>後半になるほど、視線は「自分」から「君」へと移っていきます。<br>
「迷いの中 握った手を / 離さないでいて」「信じる理由はここにあるから」、そして最後の「そばにいるよ」という一節は、一緒に走り続ける相手=ファンへの言葉としても受け取れます。<br>
アンコールでトロッコに乗り、サイン入りのボールを客席へ投げながらこの曲を歌ったという演出とも、きれいに重なる歌詞です。<br>
作詞・作曲の川尻蓮さんが「新世界」という番組のために書いた曲だけに、「君と僕で創る新世界」という一行がKO1KEYZ ver.では特別な重みを持っています。</p>
<!-- /wp:paragraph -->
