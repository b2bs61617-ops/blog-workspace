正面についた黒い丸ワッペン。
Travis Japanのドライブ動画に映り込んだ、中村海人のグレーのニット帽(ビーニー)を見てそこに目が止まった人も多いのではないでしょうか。
ワッペンの中のロゴをよく見ると、単なる装飾ではなく、あるハイブランド同士のコラボレーションを示すサインになっています。

正体はMONCLER(モンクレール)とRick Owens(リック・オウエンス)のコラボレーションライン「MONCLER + RICK OWENS」です。
なぜこのロゴだけでブランドを特定できるのか、そして「MONCLER + RICK OWENS」がどういうコラボなのかを、この記事でまとめて解説します。

話題になったのはどんな動画?

話題の動画は、Travis Japan公式YouTubeチャンネルで配信されたドライブ企画の一本です。
タイトルは「Travis Japan【ドライブ】うみの悲願が遂に!?マグロ一本釣りへの道が始動」で、中村海人がかねてから抱いていた「マグロを一本釣りしたい」という願いを叶えるべく、車移動中のメンバートークからその第一歩が始動する様子が収められています。

車内トークパートでは、運転席・後部座席にメンバーが分乗し、これから向かう場所について話す場面が続きます。
その中で、中村海人がグレーのニット帽にサングラスを頭に乗せたスタイルで画面に映っており、このニット帽のブランドに視聴者の注目が集まりました。
なお、この帽子が中村海人の私物なのか、スタイリストが用意したものなのかは番組内で明言されておらず、現時点では不明です。

ニット帽の特徴

動画に映ったニット帽には、次のような特徴が確認できます。

  • グレー系の目の詰まったリブニット素材
  • 裾を折り返した(カフ付き)ショート丈のシルエット
  • 正面に配された黒い円形のワッペン
  • ワッペンの中に白いアウトラインのマークと、縦2本のラインが入ったロゴ

    • この「円形の輪郭ロゴ」と「縦2本のライン」という組み合わせが、ブランドを特定する最大の手がかりになります。

    ニット帽の正体は「MONCLER + RICK OWENS」

    2つのブランドロゴが合体した特別なデザイン

    このワッペンのロゴは、モンクレールの象徴的な鶏(にわとり)のマークのアウトラインの中に、リック・オウエンスのデザインコードである縦2本のストライプが配置された、両ブランドのコラボレーション専用ロゴです。
    モンクレール単体のロゴでもリック・オウエンス単体のロゴでもない、「MONCLER + RICK OWENS」のラインだけに使われる意匠のため、このロゴが確認できればブランドはほぼ特定できます。

    「MONCLER + RICK OWENS」とはどんなコラボ?

    「MONCLER + RICK OWENS」は、フランス発のダウンジャケットブランド・モンクレールと、アメリカ出身でパリを拠点に活動するデザイナー、リック・オウエンスによるコラボレーションラインです。
    モンクレールが様々なデザイナー・ブランドと組む企画「Moncler Genius」の一員として2020年にスタートし、以降はシーズンごとに新作コレクションが発表される定番コラボとして続いています。

    モンクレール本来の防寒性・機能性の高いダウンジャケットに、リック・オウエンスならではのドレープを効かせたシルエットやくすみカラーを掛け合わせたアウターが看板商品ですが、Tシャツやパンツなどのアパレル、ニット帽・サングラス・ブーツといった小物まで幅広く展開されているのが特徴です。

    ニット帽の価格・販売元は?

    ニット帽1枚で数万円台というのはハイブランドらしい価格設定ですが、シンプルな見た目のわりに希少性・人気とも高いアイテムであることがうかがえます。

    アバンギャルドなデザインで芸能人にも人気

    リック・オウエンスは黒を基調としたミニマルかつ独特のシルエットで知られるデザイナーで、そのアバンギャルドな作風は「ダークウェア」とも呼ばれ、国内外問わず多くの芸能人・アーティストから支持されています。
    モンクレールとのコラボラインもこの世界観を色濃く受け継いでおり、機能性重視の一般的なアウトドアブランドの帽子とは一線を画す、シックで大人っぽい雰囲気に仕上がっているのが特徴です。
    動画で確認できたのはグレー一色というごくシンプルな配色でしたが、それでも正面のロゴひとつでコラボものだと分かってしまうところに、このラインの認知度の高さが表れています。

    まとめ

    Travis Japanのドライブ企画動画で中村海人が被っていたニット帽は、モンクレールとリック・オウエンスによるコラボレーションライン「MONCLER + RICK OWENS」のアイテムであることが分かりました。
    決め手になったのは、モンクレールの鶏マークのアウトラインとリック・オウエンスの縦2本ラインを組み合わせた、コラボ専用の丸型ロゴです。
    地味に見えて実は主張のあるアイテムを、車内という何気ないシーンでさらりと身につけているところが、今回のちょっとした見どころと言えそうです。
