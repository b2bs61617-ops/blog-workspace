## KO1KEYZのマイナビ TGC出演は配信で見られる？

<!-- wp:html -->
<div style="border:1px solid #ddd9d3;border-left:4px solid #8a8378;border-radius:4px;padding:10px 16px;margin:0 0 16px 0;background:#f7f6f4;">
<p style="margin:0;"><strong>配信:</strong>ABEMA(無料生中継/「ABEMAでリアタイTGC」)</p>
<p style="margin:4px 0 0 0;"><strong>日時:</strong>2026年9月19日(土)13:10〜21:30予定</p>
<p style="margin:4px 0 0 0;"><strong>料金:</strong>無料(会員登録・課金なしで視聴可)</p>
<p style="margin:4px 0 0 0;"><strong>見逃し:</strong>TGC公式のLINE VOOM・X・YouTubeで13:40頃から30分遅れのリピート配信</p>
</div>
<!-- /wp:html -->

マイナビ TGCは毎回、開催当日にABEMAで全編を無料生中継しています。<br>
2026 A/Wも同様で、9月19日(土)の13:10からABEMAの無料生中継がスタートし、21:30頃までステージの模様が届けられる予定です。<br>
<strong><span class="swl-marker mark_yellow" style="font-size:1.15em;">ABEMAはスマホアプリでもパソコンのブラウザでも視聴でき、会員登録やチケット購入をしなくても再生できます。</span></strong><br>
現地に足を運べなくても、KO1KEYZのスペシャルライブをリアルタイムで応援できるということです。

リアルタイムで見られない場合の受け皿として、TGC公式のLINE VOOM・X(旧Twitter)・YouTubeでは、本編開始からおよそ30分遅れのリピート生配信が予定されています(13:40頃スタート予定)。<br>
ただしこれは「30分ずらして同じ配信をもう一度流す」形式で、好きなタイミングで頭出しできる恒久的なアーカイブとは違います。<br>
TGCは出演時間・出演順が事前に細かく公開されないことも多いため、KO1KEYZのステージを確実に見たいなら、13:10の生中継開始から通しで視聴しておくと安心でしょう。

東京ガールズコレクション(TGC)は、2005年に始まった日本最大級のファッション&音楽の祭典です。<br>
「日本のリアルクローズ(等身大の洋服)を世界へ発信する」というコンセプトのもと、春夏・秋冬の年2回開催され、人気モデルによるランウェイとアーティストのライブステージが交互に展開されます。<br>
主催はW TOKYOで、2026 A/Wは通算43回目の開催にあたり、テーマは「NEW GRAVITY」と発表されています。

KO1KEYZにとって、マイナビ TGCは初めての国内大型ファッションイベントへの出演です。<br>
出演が発表されたのは2026年7月30日で、10月7日のデビューより前のタイミングでの大舞台となります。<br>
先輩にあたるJO1・INI・ME:Iも同じ日プシリーズから誕生し、TGCをはじめとする大型イベントで存在感を示してきました。<br>
デビュー前のKO1KEYZがどんなパフォーマンスを見せるのか、期待が高まっています。
