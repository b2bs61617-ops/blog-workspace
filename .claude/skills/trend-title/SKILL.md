# トレンドブログ タイトル作成スキル

参考サイト: https://himicci.net/sitemap/

## タイトルパターン

**人物プロフィール系**
```
【○○】年齢何歳?wiki経歴学歴!
【○○】顔画像は?Wiki経歴学歴プロフィールまとめ!
```

**家族・結婚系**
```
【○○】結婚や妻･子供など家族構成!
【○○】結婚相手は誰?
【○○の結婚相手】△△は何者?
```

**炎上・スキャンダル系**
```
【○○】何した?契約解除理由なぜ?
【○○】不倫相手は誰?
【○○】退団理由なぜ?
```

**事件・犯罪系**
```
【○○事件】現場どこ?
【○○】顔画像は?動機やSNS!
```

## タイトル作成の鉄則

| 要素 | ルール |
|---|---|
| 人名 | 必ずタイトルに入れる(検索はほぼ「人名+キーワード」) |
| 疑問ワード | 「なぜ?」「誰?」「何した?」「どこ?」を使う |
| 【カッコ】 | 人名を【】で囲む(視認性UP+SEO) |
| !(感嘆符) | 末尾につける(クリック率アップ) |
| 速報性 | 話題になった直後に公開する |

戦略の核心: 「今話題の人物を検索するユーザーの疑問をそのままタイトルにする」→ 検索需要が爆発している瞬間を狙い打ちにする。

## ずらし戦略(重要・本命)

**なぜずらすのか:** メイン記事(例:「〇〇 契約解除 理由」)は大手ニュースサイト・強いブロガーが即日公開し競合が強すぎる。「ずらし記事」は大手が書かない個人情報系のテーマなので競合が少なく上位を取りやすい。

**ずらし記事のテーマ一覧:**

| テーマ | タイトル例 |
|---|---|
| 歴代彼氏・彼女 | 【○○】歴代彼氏は誰?熱愛の噂まとめ! |
| 学歴・高校 | 【○○】高校・学歴はどこ?出身地も調査! |
| 両親の職業 | 【○○】父親・母親の職業は?家族構成を調査! |
| 兄弟姉妹 | 【○○】兄弟はいる?姉妹の現在も調査! |
| 実家・地元 | 【○○】実家はどこ?出身地や地元を調査! |

**記事セットの基本:** トレンドが発生したら必ずセットで書く。1) メイン記事(話題の出来事そのもの、競合多いが必要)、2) ずらし記事(個人情報系、競合少・上位取りやすい ← 本命)。

**How to apply:** 記事提案時は必ずメイン1本+ずらし複数本をセットで出す。ずらし記事の情報収集は[sns-researchスキル](../sns-research/SKILL.md)を使う。
