# 学歴・家族構成・彼女記事の書き方スキル

参考サイト: https://chomoand-1.com/ (分析記事数: 学歴7本・家族構成2本・彼女1本)

共通デザインルール(SWELLテーマのキャプションボックス・マーカー等)は[wiki-articleスキル](../wiki-article/SKILL.md)と共通。以下も参照:

```html
<!-- 小タイトル型(プロフィール・まとめに使用) -->
<div class="swell-block-capbox cap_box is-style-small_ttl">
  <div class="cap_box_ttl">プロフィール</div>
  <div class="cap_box_content">(内容)</div>
</div>

<!-- ボーダー上タイトル型(学校・補足説明に使用) -->
<div class="swell-block-capbox cap_box is-style-onborder_ttl">
  <div class="cap_box_ttl">〇〇高校ってどんな学校?</div>
  <div class="cap_box_content">(内容)</div>
</div>
```

テキストマーカー(1記事1〜2色に統一):
```html
<span class="swl-marker mark_orange">学校名・人名・番組名</span>
<span class="swl-marker mark_green">重要キーワード</span>
<span class="swl-marker mark_yellow">偏差値・数字</span>
```

インデントボックス(SNS・コメント引用): `<p class="is-style-dent_box wp-block-paragraph">"引用コメントのテキスト"</p>`

✔ボーダーリスト(特徴列挙): `<p class="has-border -border02 wp-block-paragraph">✔ 項目1<br>✔ 項目2</p>`

## 【学歴記事】テンプレート

**タイトルパターン:** 「〇〇の学歴は?偏差値〇〇の名門校出身の逸材だった!」/「〇〇の学歴は?高校はどこ?偏差値〇〇の高学歴説を徹底調査!」/「〇〇の学歴は?有名大学合格者を多数輩出する超名門校出身!」

ポイント: 「学歴は?」を必ずタイトルに入れる。偏差値の数字を入れるとクリック率UP。「名門校」「逸材」「高学歴」などのキャッチコピーをつける。

**記事構成:**
```
リード文(100〜150字): 番組名+人名+「学歴について徹底調査しました」
プロフィール表(キャプションボックス): 名前・読み方・生年月日・出身地・身長・所属
目次
H2「〇〇の学歴は?」
  H3「小学校は?」(非公表の場合はその旨を記載)
  H3「中学校は?」
  H3「高校は?」
    └ キャプションボックス(onborder_ttl)「〇〇高校ってどんな学校?」
      所在地・最寄駅(表形式)、偏差値(mark_yellowで強調)、学科・特徴
    └ Googleマップ埋め込み(z=14程度)
    └ 部活・エピソード(noteやYouTubeから引用)
  H3「大学は?」(または「現在の活動は?」): 学部・サークル・受賞歴
H2「まとめ」: キャプションボックス(small_ttl)+✔箇条書きで再掲。「今後の活躍が楽しみですね!」で締め
```

**学校情報の調査手順:**
1. minkou.jp または sconavi.com で偏差値・学科を確認
2. Wikipedia または公式サイトで住所・最寄り駅を確認
3. Googleマップ埋め込み: `https://maps.google.com/maps?q=学校名&t=&z=14&ie=UTF8&iwloc=&output=embed`(z=14目安、width="100%" height="350")

**文体:** 「逸材だった!」「素晴らしいですね」などで感動を演出。未確認情報は「〜らしいです」「〜のようです」「〜と考えられます」。偏差値や有名卒業生で学校のすごさを伝える。YouTubeやnoteから部活・エピソードを引用(onborder_ttlの引用枠で)。

## 【家族構成記事】テンプレート

**タイトルパターン:** 「〇〇の家族構成は?父親は〇〇、母親・兄弟についても調査!」/「〇〇の家族構成は〇人家族!父・母・〇〇はどんな人?」

ポイント: 「家族構成は?」を必ずタイトルに入れる。父親の職業など特徴的な情報をタイトルに入れるとクリック率UP。

**記事構成:**
```
リード文(100〜150字): 番組名+人名+「家族構成について徹底調査しました」
プロフィール表(キャプションボックス)
目次
H2「〇〇の家族構成」
  H3「何人家族?」(全体像を先に提示)
  H3「父親は?」: 職業・エピソード・SNS情報
  H3「母親は?」: 職業・エピソード
  H3「兄弟・姉妹は?」(いる場合): 年齢・職業・エピソード
H2「まとめ」: キャプションボックス(small_ttl)内に✔箇条書き(お母さん/父親/兄弟姉妹/家庭環境)。「今後の活躍が楽しみですね!」などで締め
```

**まとめのHTML例:**
```html
<div class="swell-block-capbox cap_box is-style-small_ttl">
  <div class="cap_box_ttl">〇〇の家族構成まとめ</div>
  <div class="cap_box_content">
    <p class="has-border -border02 wp-block-paragraph">
      ✔ <strong>お母さん</strong>:〇〇<br>
      ✔ <strong>父親</strong>:〇〇<br>
      ✔ <strong>兄弟姉妹</strong>:〇〇<br>
      ✔ <strong>家庭環境</strong>:〇〇
    </p>
  </div>
</div>
```

**文体:** 家族それぞれにセクションを設けて丁寧に紹介。「どんな家族に育てられたのか」という視点で興味を引く。父親・母親の職業や教育方針を掘り下げる。未確認情報は「〜と伝えられています」「〜のようです」。YouTube動画・コント・配信からエピソードを引用(onborder_ttlの引用枠で)。

## 【彼女(彼氏)記事】テンプレート

**タイトルパターン:** 「〇〇に彼女はいる?元カノの噂や好きなタイプを徹底調査!」/「〇〇の彼女は誰?熱愛情報・好きなタイプまとめ!」

ポイント: 「彼女はいる?」という問いかけ形にするとクリック率UP。「元カノ」「好きなタイプ」など関連キーワードも盛り込む。

**記事構成:**
```
リード文(100〜150字): 人名+「彼女について気になる方も多いのでは?調査しました」
プロフィール表(キャプションボックス)
目次
H2「現在彼女はいる?」: 現状の結論を先に提示(「確認されていません」など)
H2「元カノ・熱愛の噂は?」: 噂の相手と根拠・真偽。インデントボックスでSNSコメントを引用
H2「好きなタイプは?」: 本人発言・インタビュー情報。✔ボーダーリストで好みを列挙
H2「まとめ」: 箇条書きで要点再掲(彼女の有無/過去の噂/好きなタイプ)。「今後の活躍が楽しみですね!」で締め
```

**文体:** 批判・断言は避け「〜とされています」「〜のようです」で中立を保つ。「気になりますね!」「ドキドキしますね!」などファン目線の表現。SNSや動画からの情報は「〜との声も」でやんわり紹介。真偽不明の噂は「現時点では確認できていません」と必ず添える。

## 3記事共通の書き方ルール

1. タイトルに「?」を入れる(検索意図と一致しクリック率UP)
2. 冒頭で結論を先出し(読者が離脱しにくい)
3. プロフィール表は必ず入れる
4. 各H3に学校・人物の補足説明ブロックを入れる(信頼性UP・文字数UP)
5. まとめはキャプションボックス(is-style-small_ttl)+✔箇条書き
6. 締めは「楽しみですね!」「注目していきましょう!」で応援トーンに統一

情報が見つからない場合は[sns-researchスキル](../sns-research/SKILL.md)で掘る。地図埋め込み・文体ルールは[docs/rules.md](../../../docs/rules.md)参照。
