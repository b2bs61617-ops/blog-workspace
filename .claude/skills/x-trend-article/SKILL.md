# Xトレンド自動記事化スキル

`tools/x-trend-monitor/trend_monitor.py`(6時間おきのタスクスケジューラ実行)が新トレンドを検知すると、
`claude -p` 経由でこのスキルが呼ばれる。**フェーズ1運用: 下書きまで全自動、公開はユーザー承認制**(2026-07-10開始)。

## 絶対ルール(フェーズ1)

- **公開しない。** 投稿は必ず`status: draft`。publishへの変更はユーザーが「公開して」と言ったときだけ([publish](../publish/SKILL.md)スキル)。
- **削除しない。** WordPress記事・ファイルの削除は一切行わない([docs/wordpress.md](../../../docs/wordpress.md))。
- **裏取りできない情報は書かない。** 全自動運用なので、誤情報・名誉毀損リスクは通常より厳しく見る。

## 実行フロー

1. **レポートを読む**: 引数で渡された `tools/x-trend-monitor/reports/trends_*.json` を読む(最大3トレンド)。

2. **記事化の判断**(トレンドごと):
   - **採用**: 「なぜ？」「誰？」「どこ？」「いつまで？」と検索されそうなもの(2026-07-10にユーザー指示で人物以外にも拡大)。
     - 人物・グループ・作品(「誰？」「何者？」が発生するもの)
     - イベント・祭り・ライブ・コラボ企画(「いつ・どこ・チケット・混雑」が発生するもの)
     - 食べ物・新商品・コンビニ商品(「どこで買える・いつまで・値段」が発生するもの)
     - ネットミーム・流行語(「意味・元ネタ」が発生するもの)
   - 種別ごとに狙う検索キーワードは下の「検索意図の狙いどころ」を参照。
   - **見送り**: 以下は記事化しない。
     - 災害・事故・事件(被害者や逮捕者が絡むもの)。名誉毀損・不謹慎リスクが高いため
     - 政治・選挙・宗教などの敏感なテーマ
     - テレビ番組の実況タグ・大喜利タグなど、検索需要が続かない定型ハッシュタグ
     - 企業キャンペーン・プロモーション由来のトレンド
     - リサーチしても「なぜトレンド入りしたか」が特定できなかったもの
   - 判断に迷ったら見送り(見送り理由は最後のLINE通知に含める)。

3. **リサーチ**: WebSearchで「なぜ今トレンド入りしたか」を特定し、事実関係を複数ソースで裏取りする。
   Yahoo!リアルタイム検索(`https://search.yahoo.co.jp/realtime/search?p={トレンド語}`)のWebFetchも有効。

3.5. **検索者の疑問を書き出す(執筆前に必須。2026-07-10にユーザー指示で追加)**:
   タイトル・見出しを決める前に、**「この出来事を知った人は、次に何を知りたくなるか？」を疑問文で5〜10個書き出す**。
   ニュースは「何が起きたか」しか伝えないので、検索の疑問は必ず「その先(背景・意味・影響)」に生まれる。
   - 疑問が湧く2大パターン:
     - **時間の空白**: 表舞台から消えていた人・久しぶりの話題 → 「いつから？」「その間何してた？」
     - **キャラとのギャップ**: イメージと違う行動 → 「本物？」「なぜ？」「今後どうなる？」
   - 例: 「嵐の大野智がインスタでタトゥーを公開」なら →「いつから入れてた？(休止中？)」「本物？」
     「デザインと意味は？」「なぜ今公開した？」「嵐の再始動に影響は？」「ファンの反応は？」
   - 書き出した疑問の中から、競合が空いているもの(手順4の競合チェックと突き合わせる)を選び、
     **疑問文をほぼそのままタイトル・H2/H3にする**。「検索意図の狙いどころ」表は型の参考、
     ここでの疑問の書き出しが本体。型に無い疑問が見つかったらそちらを優先してよい。
   - **実際の検索キーワードは「固有名詞+対象物+疑問語」の3語に圧縮される**(2026-07-10ユーザー指導)。
     例:「大野くんのタトゥーの意味は？」→ 実際に打たれるのは「大野智 タトゥー 意味」。
     タイトルにはこの3要素を必ず含め、表記揺れ(タトゥー/刺青、フルネーム/愛称)も本文中で自然に拾う。
   - **「まだ答えが世に無い疑問」ほど検索が長く続く**。本人が語っていない「意味」「理由」などは
     答えが出るまで検索され続けるので、ファンの考察・状況証拠を丁寧にまとめる価値が高い
     (ニュースで即答えが出る疑問は数日で検索が消える)。

4. **重複・競合チェック(執筆前に必須。2026-07-10にユーザー指示で追加)**:
   - **自サイト重複**: `GET https://chomoand.com/wp-json/wp/v2/posts?search={キーワード}`で既存記事を検索。
     同一テーマの記事が既にあれば新規作成せずスキップ(LINE通知にその旨を含める)。
   - **競合SERP調査**: 狙うクエリ(「〇〇 何者」「〇〇 嫁」など、ずらしクエリを2〜3個)をWebSearchして、
     既に上位を取っている記事の顔ぶれを確認する。**既に強い記事があるクエリに後発で書いても順位はつかない**。
     | 検索結果の状況 | 判断 |
     |---|---|
     | Wikipedia・大手ニュース・公式・データ系サイト(年俸DB等)のみ | GO(検索意図が違うので、ずらし記事で勝てる) |
     | 同じ検索意図の個人ブログ/トレンドブログが既にある | その角度は捨てる。誰も書いていない角度(今回のトレンドで新たに生まれた疑問など)が残っていればそこにタイトル・見出しを寄せる。全角度が埋まっていたら見送り |
     | トレンド発生から数時間以内で個人ブログ未参入 | 最速公開でGO(速報性が最大の武器) |
   - どの角度で勝ちにいくか(または見送るか)の判断結果は、最後のLINE通知に1行で含める。

5. **執筆**: [trend-title](../trend-title/SKILL.md)でタイトル決定(疑問形)、[docs/rules.md](../../../docs/rules.md)準拠で執筆。
   - 結論ファースト、最低2,500字、句点で文が終わったら`<br>`改行
   - 場所が特定できていればGoogleマップ埋め込み
   - 人物ネタは[wiki-article](../wiki-article/SKILL.md)/[gakureki-kazoku-kanojo](../gakureki-kazoku-kanojo/SKILL.md)のテンプレを流用してよい
   - 既存の関連記事があれば内部リンクを張る
   - 推測は「〜の可能性があります」と明示し、断定しない

6. **下書き投稿**: [blog-upload](../blog-upload/SKILL.md)の手順で**chomoand.com**(`WP_TREND_*`)に`status: draft`で投稿し、アイキャッチも生成・設定する([docs/eyecatch-style.md](../../../docs/eyecatch-style.md))。
   下書き更新時は`status: draft`を必ずペイロードに含める([docs/wordpress.md](../../../docs/wordpress.md)の2026-07-10の注意点)。

7. **LINE通知**: 処理結果をまとめて1通送る。
   - 下書きあり: `python tools/line_notify.py "トレンド「{語}」の記事下書きができたワン。中身を確認して「公開して」と言ってほしいワン。タイトル: {タイトル} 編集: https://chomoand.com/wp-admin/post.php?post={ID}&action=edit"`
   - 全件見送り: `python tools/line_notify.py "Xトレンド{N}件を検知したけど、記事化は見送ったワン。理由: {簡潔に}"`

8. **後片付け**: 処理済みレポート(`.json`と`.claude.log`)を `tools/x-trend-monitor/reports/processed/` に移動する。

## 検索意図の狙いどころ(ネタ種別ごと)

トレンド語と一緒に検索される複合キーワードの定番。タイトル・見出し(H2/H3)はここから組む([trend-title](../trend-title/SKILL.md)の疑問形・【】・ずらし戦略と併用)。

| ネタ種別 | 最も検索される複合キーワード(優先順) |
|---|---|
| 人物(無名・新顔) | 誰/何者 → wiki/プロフィール/年齢/本名 → 高校/大学(学歴) → 彼氏彼女/結婚 → 実家/出身 |
| 人物(有名人の話題) | なぜ/理由/何した → 相手は誰 → 現在 → 昔/若い頃 |
| イベント・祭り | いつ/どこ → チケット/申込方法 → 混雑/待ち時間 → 屋台/出演者 → 駐車場/アクセス → 雨天中止 |
| 食べ物・新商品 | どこで買える/販売店舗 → いつまで(販売期間) → 値段 → カロリー → 味の口コミ/まずい? → 通販/お取り寄せ |
| ミーム・流行語 | 意味 → 元ネタ → 誰が言った → なぜ流行 |

- 「どこ」系が答えられる(店舗・会場が特定できる)ときはGoogleマップ埋め込みを忘れない([docs/rules.md](../../../docs/rules.md))。
- イベント・食べ物ネタは大手ニュースが「ずらし」を書かないぶん、人物ネタより上位を取りやすい。「メイン(何が起きた)+ずらし(どこで買える/混雑は)」のセット構成が理想。
