# 恋愛リアリティ番組 出演者wikiスキル(chomoand.com)

chomoand.comは2026-07-14に**「恋愛リアリティ番組の出演者wiki」特化サイト**へ転換した。経緯は[docs/chomoand-pivot.md](../../../docs/chomoand-pivot.md)参照。このスキルはその実務手順。

記事の書き方そのもの(HTML・SWELLクラス・文体・プロフィール表)は[wiki-article](../wiki-article/SKILL.md)・[gakureki-kazoku-kanojo](../gakureki-kazoku-kanojo/SKILL.md)スキルと共通。ここでは**恋リア固有の部分だけ**を書く。

## 最重要: 勝ち筋は「出演者発表直後」

このジャンルで勝てるかどうかは、ほぼ**タイミングだけ**で決まる。

1. 番組公式が新シーズンの出演者を発表する(第1弾・第2弾と小出しにされることが多い)
2. その瞬間から「◯◯(名前) 高校」「◯◯ 本名」「◯◯ インスタ」の検索が立ち上がる
3. **しかしまだ誰も書いていない。放送開始まで2〜4週間の空白期間がある**
4. 大手メディアは「メンバー発表」のニュースは書くが、**個々の出演者の学歴・家族構成は絶対に書かない**(一般人だから)。だから空白は放送後も埋まらない

**→ 出演者発表を検知したら、他の作業より優先して着手する。放送開始を待たない。** これがKO1KEYZで勝てたのと同じ構造。

## 対象番組(2026-07時点)

日本人出演者が出る番組を優先する。韓国・海外番組は出演者の学歴を日本語で掘るのが困難なため優先度を下げる。

| 番組 | 配信 | 特徴 | 優先度 |
|---|---|---|---|
| 今日、好きになりました。 | ABEMA | **最優先**。シーズン更新が高頻度でネタが途切れない。出演者は現役高校生の一般人=競合ゼロ。視聴者層が10〜20代前半でSNS検索が活発 | ★★★ |
| オオカミくんには騙されない / オオカミちゃん | ABEMA | 出演者に読者モデル・インフルエンサーが混ざる。知名度がある分だけ競合はやや増える | ★★ |
| ボーイフレンド | Netflix | 日本初の男性同士の恋リア。話題性が高い | ★★ |
| あいの里 | Netflix | 出演者の年齢層が高い。学歴より経歴・職業の需要が強い | ★★ |
| バチェラー・ジャパン / バチェロレッテ・ジャパン | Amazon | 出演者が社会人。職業・年収・経歴の検索需要が強い | ★★ |
| 韓国系(乗り換え恋愛・Shuffle of Love・EDEN等) | ABEMA | 出演者が韓国人で日本語情報が薄い。学歴を掘るのが難しい | ★ |

**番組リストは陳腐化する。着手前に必ず最新の放送・配信状況をWebSearchで確認すること。**

## 出演者発表の検知手順(現状は手動)

自動監視の仕組みはまだ無い(将来の課題)。当面は以下を手動で回す。

1. `恋愛リアリティ 2026年◯月 新シーズン 出演者 発表` でWebSearch
2. `今日好き ◯◯編 メンバー` のように番組名+シーズン名で個別に検索
3. ABEMA公式(`abema.tv/lp/kyousuki-official`等)・PR TIMES・ORICON・モデルプレスがメンバー発表の一次ソースになりやすい
4. **第1弾発表の後に第2弾・第3弾が来る**ので、1回書いて終わりにせず継続的に確認する

## 記事の型(恋リア版)

1人の出演者につき複数記事に分けて内部リンクで束ねる。KO1KEYZと同じ「1人=複数記事」戦略。

### A. 出演者wiki記事(**最速で書く。主力**)

- タイトル: `【今日好き】くうがのwiki風プロフィール!高校・本名・インスタは?`
- 型は[wiki-article](../wiki-article/SKILL.md)をそのまま使う。読み替えは以下:
  - リード文の「番組名」→ 恋リア番組名 + シーズン名(例:『今日、好きになりました。夏休み編2026』)
  - H3「前世は?」→ **「過去の芸能活動は?」**(モデル・子役・他の恋リア出演歴・TikTok/Instagramでの活動があるか)
  - H3「◯◯スクール出身」→ **「SNS(インスタ・TikTok)は?」**(恋リアはここの検索需要が非常に大きい)
  - プロフィール表に**「学年」「出身地」「身長」「MBTI」**を必ず入れる(番組公式が出していることが多い)
- 出演者発表直後は情報が少ないので、**分かっていることだけで一度公開し、放送が進むたびに追記・リライトする**。完璧を待たない。

### B. 学歴記事

- タイトル: `【今日好き】くうがの高校はどこ?学歴・偏差値を調査!`
- 型は[gakureki-kazoku-kanojo](../gakureki-kazoku-kanojo/SKILL.md)の学歴テンプレート。
- **恋リア出演者の学校は本人が公言していないことが多い**。制服・地元情報・SNS投稿からの推定になるため、断定は絶対にしない(下の「線引き」参照)。

### C. カップル・結末記事(**放送後**)

恋リア固有の記事タイプ。放送が進んでから書く。

- タイトル例: `【今日好き】くうがは誰とカップル成立した?最終回の結末をネタバレ!` / `【今日好き】くうがとみのりは今も付き合ってる?番組後の関係を調査!`
- 検索需要が最終回前後に爆発する。**放送日に合わせて公開できるよう下書きを準備しておく**。

### D. 番組メンバー一覧まとめ記事(**ハブ記事**)

- タイトル例: `【今日好き】夏休み編2026のメンバー一覧!出演者のプロフィールまとめ`
- 全出演者を表で一覧化し、各出演者の個別記事(A・B・C)へ内部リンクを張る**ハブ**にする。
- 「今日好き 夏休み編 メンバー」という検索を受け止めて個別記事に流す導線。**個別記事より先に、または同時に作る。**

## プライバシーの線引き(絶対厳守)

出演者は**芸能人ではなく一般人**。今日好き系は**現役高校生(未成年)**。名誉毀損・プライバシー侵害・削除要請のリスクが芸能人記事より明確に高い。以下を守る。

### 書いてよい情報源(これ以外を根拠にしない)

1. **番組内で本人が話した内容**(自己紹介・トーク・テロップ)
2. **本人の公開SNSでの発信**(鍵アカウントの中身は使わない)
3. **本人・事務所・番組公式の発表**(公式プロフィール・プレスリリース)

### 書かないこと

- 実家の住所・最寄駅レベルの特定(「◯◯県出身」までにとどめる)
- 本人が公言していない在籍校・勤務先の**断定**(推定として書く場合も「〜と推測されます」を必ず添える)
- 番組出演前の交際相手の実名・過去の恋愛遍歴の詮索
- **未成年出演者を性的な文脈で扱う記述**(容姿への言及は「かわいい」「イケメン」といった一般的な範囲を超えない)
- 家族の実名・職場など、本人が番組/SNSで話していない家族の個人情報

### 学校名の扱い(特に注意)

高校特定は検索需要が最も大きい一方で、最もリスクが高い。

- 本人が公言している → 断定してよい
- 制服・地元情報・SNSから推定できる → **「〜の可能性が高いです」「〜と推測されます」で書く。断定しない**
- 根拠が薄い → **書かない**。「現時点では公表されていません」と正直に書き、周辺情報(出身地の高校事情など)で記事の価値を作る

**迷ったら書かない。** 1記事のPVより、削除要請・炎上でサイトごと失うほうが損害が大きい。

## 投稿先・カテゴリ

- 投稿先は**chomoand.com**(`.env`の`WP_TREND_*`。キー名は旧トレンドブログ時代のまま)
- 恋リア用カテゴリは**まだ無い**。番組名ごとにカテゴリを新設する(例:「今日、好きになりました。」)。最新のカテゴリID一覧は[docs/wordpress.md](../../../docs/wordpress.md)、または `GET https://chomoand.com/wp-json/wp/v2/categories?per_page=100` で確認
- 投稿は[blog-uploadスキル](../blog-upload/SKILL.md)、公開は[publishスキル](../publish/SKILL.md)
