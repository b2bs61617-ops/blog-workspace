# 恋愛リアリティ番組 出演者wikiスキル(chomoand.com)

chomoand.comは2026-07-14に**「恋愛リアリティ番組の出演者wiki」特化サイト**へ転換した。経緯は[docs/chomoand-pivot.md](../../../docs/chomoand-pivot.md)参照。このスキルはその実務手順。

記事の書き方そのもの(HTML・SWELLクラス・文体・プロフィール表)は[wiki-article](../wiki-article/SKILL.md)・[gakureki-kazoku-kanojo](../gakureki-kazoku-kanojo/SKILL.md)スキルと共通。ここでは**恋リア固有の部分だけ**を書く。

## 最重要: 勝ち筋は「出演者発表直後」

このジャンルで勝てるかどうかは、ほぼ**タイミングだけ**で決まる。

1. 番組公式が新シーズンの出演者を発表する(第1弾・第2弾と小出しにされることが多い)
2. その瞬間から「◯◯(名前) 高校」「◯◯ 本名」「◯◯ インスタ」の検索が立ち上がる
3. **しかしまだ誰も書いていない。放送開始まで2〜4週間の空白期間がある**
4. 大手メディアは「メンバー発表」のニュースは書くが、**個々の出演者の学歴・家族構成は絶対に書かない**(一般人だから)。だから空白は放送後も埋まらない

**→ 出演者発表を検知したら、他の作業より優先して着手する。放送開始を待たない。** これがKO1KEYZで勝てたのと同じ構造。

## 対象番組(2026-07時点)

日本人出演者が出る番組を優先する。韓国・海外番組は出演者の学歴を日本語で掘るのが困難なため優先度を下げる。

| 番組 | 配信 | 特徴 | 優先度 |
|---|---|---|---|
| 今日、好きになりました。 | ABEMA | **最優先**。シーズン更新が高頻度でネタが途切れない。出演者は現役高校生の一般人=競合ゼロ。視聴者層が10〜20代前半でSNS検索が活発 | ★★★ |
| オオカミくんには騙されない / オオカミちゃん | ABEMA | 出演者に読者モデル・インフルエンサーが混ざる。知名度がある分だけ競合はやや増える | ★★ |
| ボーイフレンド | Netflix | 日本初の男性同士の恋リア。話題性が高い | ★★ |
| あいの里 | Netflix | 出演者の年齢層が高い。学歴より経歴・職業の需要が強い | ★★ |
| バチェラー・ジャパン / バチェロレッテ・ジャパン | Amazon | 出演者が社会人。職業・年収・経歴の検索需要が強い | ★★ |
| シャッフルアイランド | ABEMA | タイ・サムイ島が舞台。2026-07時点でSeason7放送中、競合3サイト([docs/koi-real-competitor-analysis.md](../../../docs/koi-real-competitor-analysis.md)参照)が揃って最新記事を出す最もホットな番組。出演者に日プ女子出身・モデルなど元々知名度がある人も混ざるため、今日好きよりは競合がやや増える | ★★★ |
| 韓国系(乗り換え恋愛・Shuffle of Love・EDEN等) | ABEMA | 出演者が韓国人で日本語情報が薄い。学歴を掘るのが難しい | ★ |

**番組リストは陳腐化する。着手前に必ず最新の放送・配信状況をWebSearchで確認すること。**

## 出演者発表の検知手順(現状は手動)

自動監視の仕組みはまだ無い(将来の課題)。当面は以下を手動で回す。

1. `恋愛リアリティ 2026年◯月 新シーズン 出演者 発表` でWebSearch
2. `今日好き ◯◯編 メンバー` のように番組名+シーズン名で個別に検索
3. ABEMA公式(`abema.tv/lp/kyousuki-official`等)・PR TIMES・ORICON・モデルプレスがメンバー発表の一次ソースになりやすい
4. **第1弾発表の後に第2弾・第3弾が来る**ので、1回書いて終わりにせず継続的に確認する

## タイトルの型(競合3サイト分析ベース・2026-07-19)

恋愛ふりーくす(fstopics.com)・定番ナビ・はぴにゃんブログの全記事タイトルを調査した結果(詳細は[docs/koi-real-competitor-analysis.md](../../../docs/koi-real-competitor-analysis.md))、恋リア出演者wikiのタイトルはほぼ共通のフォーミュラに従っている。**このジャンルのタイトルは[trend-titleスキル](../trend-title/SKILL.md)の一般形より、下記の型を優先する。**

```
【番組名/通称】名前（本名） + は誰？/の高校はどこ？/のプロフィール
  + 属性キーワード(高校・身長・インスタ・経歴・SNS・本名など2〜3個)
  + まとめ！/を調査！
  + （シーズン名・編名）
```

- 疑問形で終わるタイトルが圧倒的多数(trend-titleの「左寄せの法則」と同じ思想。人名+検索属性を左に寄せる)
- シーズン名・編名を`（インチョン編）`のように末尾の括弧に必ず入れる。同じ番組でもシーズンごとに検索されるため、これが無いと機会損失になる
- 属性キーワードは欲張って2〜3個並べる(例:「高校・身長・インスタ」「本名・経歴・彼氏」)。1個だけより検索の当たり幅が広がる
- **番組名は必ずタイトル先頭で`【番組名】`のように【】で囲む**(chomoand.comは恋リア特化サイトのため、どの番組の記事か一目で分かる必要がある)。「今日好き｜」「今日好き 」のような区切り文字だけの表記は不可。2026-07-22にトモキの指示で徹底、既存の「ラヴ上等2」記事44本(ID 11642〜11685)も`【ラヴ上等2】`形式に修正済み(経緯は[docs/history.md](../../../docs/history.md))

## 記事の型(恋リア版)

1人の出演者につき複数記事に分けて内部リンクで束ねる。KO1KEYZと同じ「1人=複数記事」戦略。

**注意(2026-07-27の教訓)**: この「1人=複数記事」戦略は、KO1KEYZのように**各記事が独立して2,500字を超えられるだけの情報量がある場合のみ**有効。出演者発表直後で情報が少ない段階から機械的に「プロフィール/学歴/職業/逮捕歴」などに分割すると、1記事あたり700〜1,400字程度の薄い記事を量産することになり、サイトの品質ルール(最低2,500字)を割る。実際にラヴ上等2の76記事がこの状態になり、統合し直す羽目になった(経緯は[docs/history.md](../../../docs/history.md)参照)。**情報が少ないうちは1本の総合プロフィール記事(プロフィール+経歴+学歴+SNSなどをまとめて2,500字以上)で公開し、放送が進んで書けることが十分に増えてから、学歴記事・カップル記事などを独立した記事として切り出す**、の順番を守ること。

### A. 出演者wiki記事(**最速で書く。主力**)

- タイトル例: `【今日好き】くうが（名前）の高校はどこ？本名・インスタなどプロフィールまとめ！（インチョン編）`
- 型は[wiki-article](../wiki-article/SKILL.md)をそのまま使う。読み替えは以下:
  - リード文の「番組名」→ 恋リア番組名 + シーズン名(例:『今日、好きになりました。夏休み編2026』)
  - H3「前世は?」→ **「過去の芸能活動は?」**(モデル・子役・他の恋リア出演歴・TikTok/Instagramでの活動があるか)
  - H3「◯◯スクール出身」→ **「SNS(インスタ・TikTok)は?」**(恋リアはここの検索需要が非常に大きい)
  - プロフィール表に**「学年」「出身地」「身長」「MBTI」**を必ず入れる(番組公式が出していることが多い)
- 出演者発表直後は情報が少ないので、**分かっていることだけで一度公開し、放送が進むたびに追記・リライトする**。完璧を待たない。
- **追記・リライトで深掘りするときはWebSearchではなくSNS本体を掘る**([sns-research](../sns-research/SKILL.md)の「新規性の出どころ」参照)。WebSearchのテキスト情報には基本的に新規性が無く、本人のX/Instagram投稿・YouTube出演動画(画像・発言)にしか新しい情報は無いため。

### B. 学歴記事

- タイトル例: `【今日好き】くうが（名前）の高校はどこ？学歴・偏差値などプロフィールまとめ！（インチョン編）`
- 型は[gakureki-kazoku-kanojo](../gakureki-kazoku-kanojo/SKILL.md)の学歴テンプレート。
- **恋リア出演者の学校は本人が公言していないことが多い**。制服・地元情報・SNS投稿からの推定になるため、断定は絶対にしない(下の「線引き」参照)。

### C. カップル・結末記事(**放送後**)

恋リア固有の記事タイプ。放送が進んでから書く。

- タイトル例: `【今日好き】くうがは誰とカップル成立した？最終回の結末をネタバレ！（インチョン編）` / `【今日好き】くうがみのりが別れた！？その後付き合ったの？今現在を調査！（インチョン編）`
- 検索需要が最終回前後に爆発する。**放送日に合わせて公開できるよう下書きを準備しておく**。

### D. 番組メンバー一覧まとめ記事(**ハブ記事**)

- タイトル例: `【今日好き】夏休み編2026出演メンバー一覧｜出演者のプロフィール・SNSまとめ`
- 全出演者を表で一覧化し、各出演者の個別記事(A・B・C)へ内部リンクを張る**ハブ**にする。
- 「今日好き 夏休み編 メンバー」という検索を受け止めて個別記事に流す導線。**個別記事より先に、または同時に作る。**

## プライバシーの線引き(絶対厳守)

出演者は**芸能人ではなく一般人**。今日好き系は**現役高校生(未成年)**。名誉毀損・プライバシー侵害・削除要請のリスクが芸能人記事より明確に高い。以下を守る。

### 書いてよい情報源(これ以外を根拠にしない)

1. **番組内で本人が話した内容**(自己紹介・トーク・テロップ)
2. **本人の公開SNSでの発信**(鍵アカウントの中身は使わない)
3. **本人・事務所・番組公式の発表**(公式プロフィール・プレスリリース)

### 書かないこと

- 実家の住所・最寄駅レベルの特定(出身地は**都道府県・市レベル**までにとどめる)
- **出身小学校名**(市より狭い学区の特定になるため、未成年出演者については書かない)
- 本人が公言していない在籍校・勤務先の**断定**(推定として書く場合も「〜と推測されます」を必ず添える)
- 番組出演前の交際相手の実名・過去の恋愛遍歴の詮索
- **未成年出演者を性的な文脈で扱う記述**(容姿への言及は「かわいい」「イケメン」といった一般的な範囲を超えない)
- 家族の実名・職場・両親の職業など、**本人が番組/SNSで自ら公言していない**家族の個人情報(第三者の推測・詮索での特定は不可)
- 未成年の兄弟姉妹の実名・在籍校

### 学校名の扱い(特に注意)

高校特定は検索需要が最も大きい一方で、最もリスクが高い。

- 本人が公言している → 断定してよい
- 制服・地元情報・SNSから推定できる → **「〜の可能性が高いです」「〜と推測されます」で書く。断定しない**。TVで制服が映った=公表されたわけではないので、推測の根拠にはなるが断定の根拠にはしない
- 根拠が薄い → **書かない**。「現時点では公表されていません」と正直に書き、周辺情報(出身地の高校事情など)で記事の価値を作る
- **未成年出演者の(推測含む)在籍校について、Googleマップ埋め込みは付けない**(名前+学校+地図の組み合わせは居場所特定に直結するため、通常の学歴記事のGoogleマップ埋め込みルールをここでは適用しない)

**迷ったら書かない。** 1記事のPVより、削除要請・炎上でサイトごと失うほうが損害が大きい。

**例外(成人・非未成年の番組限定)**: 『ラヴ上等』のように出演者が全員成人の番組では、トモキの個別承認があれば「書いてよい情報源」を第三者ブログ・SNSの噂・憶測まで拡張し、犯罪歴も含めて出典明記の上で書いてよい(トモキが最終確認する前提、経緯は[docs/history.md](../../../docs/history.md)参照)。**この拡張は今日好き等の未成年出演者には絶対に適用しない。**

## 投稿先・カテゴリ

- 投稿先は**chomoand.com**(`.env`の`WP_TREND_*`。キー名は旧トレンドブログ時代のまま)
- 恋リア用カテゴリは番組名ごとに新設する運用(2026-07-20時点で既存: 今日、好きになりました。=ID34 / シャッフルアイランド=ID35 / ラヴ上等=ID36)。新しい番組は同じ要領でカテゴリを新設する。最新のカテゴリID一覧は[docs/wordpress.md](../../../docs/wordpress.md)、または `GET https://chomoand.com/wp-json/wp/v2/categories?per_page=100` で確認
- 投稿は[blog-uploadスキル](../blog-upload/SKILL.md)、公開は[publishスキル](../publish/SKILL.md)
