# テレビ番組調査スキル

## 調査先URL

`https://bangumi.org/yep/facade?pc_yjweb`

日付指定する場合はパラメータを追加: `https://bangumi.org/yep/facade?pc_yjweb&broad_cast_date=YYYYMMDD`

(今日の番組表そのものを見るだけなら `https://bangumi.org/epg/td?pc_yjweb=...` も使える)

## 手順

1. **調査期間は「翌日から1週間分」**。今日の日付は使わない(例: 今日が6/21なら6/22〜6/28を調査)。
2. **7日分のURLを並列でWebFetchする**。
3. 各日のWebFetchプロンプト: 「各テレビ局ごとに番組名と出演者(俳優・タレント・アーティストなど)をリストアップして。プロデューサー・スタッフ情報は除外」
4. 下記の「省く人物」ルールでフィルタリングする。
5. 結果を日付ごとの表形式でまとめる:

```
## YYYY年MM月DD日(曜日)

| テレビ局 | 番組名 | 出演者 |
|---------|--------|--------|
| NHK | 番組名 | 出演者名 |
```

## 対象局(6局のみ)

NHK / 日本テレビ / テレビ朝日 / TBS / テレビ東京 / フジテレビ
(TOKYO MX・地方局・BSなどは対象外)

## 省く人物のルール

**目的:** 既にブログ記事が豊富な人は検索流入が見込みにくいため、旬な・話題の人物に絞る。

**① 固定除外リスト(毎回省く):** カズレーザー、東野幸治、マツコ・デラックス、有吉弘行、明石家さんま、タモリ、笑福亭鶴瓶、内村光良、千鳥(大悟・ノブ)、オードリー(若林・春日)、さまぁ〜ず(三村・大竹)、爆笑問題(太田・田中)、くりぃむしちゅー(上田・有田)、ナインティナイン(岡村・矢部)、ダウンタウン(浜田・松本)、関ジャニ∞メンバー(司会常連)、羽鳥慎一、加藤浩次、田村淳、宮根誠司、林修、池上彰、その他「ほぼ毎週テレビに出ている」常連司会者・コメンテーター。ユーザーから追加指示があれば随時更新する。

**② 動的フィルタ:** 7日分のデータで**3番組以上に登場している人物**はトレンド性が低いと判断し、コメントをつけて省くか目立たなくする。

## 注意事項

- 調査開始日は必ず「今日の翌日」から。
- プロデューサー・番組スタッフは出演者に含めない。
- 動的コンテンツのため一部情報が取得できない場合がある。
- 声優はアニメ番組の場合のみ記載。
