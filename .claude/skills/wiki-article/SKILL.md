# 人物wiki・プロフィール・経歴記事の書き方スキル

参考サイト: https://chomoand-1.com/(91記事・25本精読分析済み)

## 記事の「型」(全体テンプレート)

```
タイトル: 「人名+のwiki風経歴は?+出身地+キャッチコピー!」
↓
リード文: 「番組名(正式名)+人名(読み仮名付き)+まだ知らない方にも〜まとめました。」
↓
H2「〇〇のwiki風プロフィール」
  └ H3「基本プロフィール」(表形式)
  └ H3「どんな性格?」(MBTI解説)
  └ H3「家族構成」「好きなもの」など任意
↓
H2「〇〇のwiki風経歴」
  └ H3「前世は?」
  └ H3「〇〇スクール出身」「〇〇番組出演」(時系列)
  └ H3「〇〇番組出演」(最新番組を最後)
↓
H2「まとめ」(約50%の記事に存在)
  └ 100〜200字の総括+「今後の活躍が楽しみです!」で締め
```

## 1. タイトルパターン

**基本フォーマット(約90%):** 「【人名】のwiki風経歴は?【出身地】出身の【キャッチコピー】!」

よく使われるキーワード: 「実力派」(約40%)、「イケメン」(約30%)、「高身長×〇〇」「ダンス×〇〇」など「×」掛け合わせ(約60%)、「〇〇出身」(EXPG、ジュノン、事務所名など)(約35%)、「4ヶ国語を操る」「ダンス歴12年」など具体的数字(約35%)

## 2. 冒頭リード文(約100〜150字、2〜3文)

**パターンA(約70%): 番組紹介→人物紹介→記事目的の宣言**
> 「2026年3月26日放送の大人気オーディション番組『PRODUCE 101 JAPAN 新世界(日プ4)』に出演の〇〇さん。本記事では、〇〇さんをまだ知らない方にもわかりやすくプロフィールや経歴をwiki風にしてまとめました。」

**パターンB(約15%): 人物の印象から入る** / **パターンC(約15%): 問いかけ形**

必須要素: 番組名(正式名)+略称、人名(漢字+読み仮名)、「まだ知らない方にも」「わかりやすく」「wiki風にして」「まとめました」、「ぜひ最後までご覧ください!」(約40%に追加)

## 3. プロフィール表の項目

**必須:** 名前 / 読み方(ひらがな・英字)/ 生年月日 / 年齢(「〇〇年〇月時点」と明記)/ 出身地 / 身長 / 趣味 / 特技 / MBTI

**頻出任意(60〜80%):** キーワード(自己表現ワード)/ ロールモデル / 夢

**やや頻出(30〜60%):** 血液型 / 体重 / 言語能力(グローバル系)/ 口癖 / 好きな食べ物 / SNS情報 / 学校・事務所

書き方ルール: MBTI型は「ISFP(冒険家タイプ)」のように括弧で補足。年齢は必ず現在時点を明記。外国出身者は「言語」欄を必ず設ける。

## 4. H2・H3見出しパターン

**H2(ほぼ固定):** 「〇〇のwiki風プロフィール」(100%) / 「〇〇のwiki風経歴」(100%) / 「まとめ」(約50%)

**H3プロフィールブロック:** 基本プロフィール(100%)、どんな性格?(約70%)、好きなもの・好きなことは?(約40%)、家族構成は?(約40%)、どんな人?(約30%)、学歴は?(約30%)

**H3経歴ブロック:** 前世は?/前世なし?(約75%)、「〇〇番組名」に出演/挑戦/参加(100%)、幼少期は?(約35%)、「〇〇スクール名」出身/在籍(約60%)

## 5. 経歴セクションの構成(時系列型・約60%)

```
H3: 前世は?(芸能歴の有無)
H3: 幼少期・スクール時代
H3: 〇〇オーディション出演(過去番組)
H3: 最新番組出演
  └ レベル分けテスト / グループバトル / ポジション評価 / コンセプト評価
```

見出し命名ルール: 番組・スクール名は「」で囲む。「出演」「挑戦」「参加」「出身」「在籍」を使い分ける。

## 6. 文末表現・語尾

- 断言系: 〜です。/〜ます。/〜ました。/〜になっています。
- 推測系(最頻出は「〜のようです」): 〜のようです / 〜と思われます / 〜かもしれません / 〜のではないでしょうか
- 感嘆・共感系: 〜ですね!(多用) / 〜が気になりますね / 〜楽しみですね! / 〜目が離せません!

## 7. 不確かな情報の表現

| 表現 | 使用例 |
|---|---|
| 〜のようです | 「TikTokライブの情報のようです」 |
| 〜と推測できます | 「5歳からダンスを始めたと推測できます」 |
| 〜可能性が高いですね | 「本格的デビューの可能性が高いですね」 |
| 詳しくは明かされていません | 「学歴の詳細は明かされていません」 |
| 〜は不明です | 「正確な情報は不明です」 |

「前世なし」の定型表現: 「明確な前世(芸能活動歴)は確認されておらず、本格的な表舞台デビューの可能性が高い」「原石タイプ」「ゼロからのスタート」

## 8. 記事の文字数目安

短め1,500〜2,500字(約20%) / 中程度2,500〜4,000字(約45%) / 長め4,000〜6,000字(約30%) / 非常に長い6,000字超(約5%)

## 9. まとめセクション(約100〜200字)

**パターンA(約60%): プロフィール総括+今後への期待** / **パターンB(約25%): 一言コメント** / **パターンC(約15%): ドラマチックな締め**

定型フレーズ: 「〇〇さんの今後の活躍が楽しみですね!」「〇〇に注目していきましょう!」「目が離せません!」

## 10. 特徴的な表現テクニック

1. **「ギャップ」演出(約70%):** 普段と本番・外見と内面の落差を強調
2. **MBTI活用(ほぼ100%):** 診断結果から人物像を描く
3. **「〇〇×〇〇」掛け算表現(約60%):** 「ブレイクダンス×美声」など
4. **評価ラベル(約80%):** 「原石」「実力派」「注目株」など
5. **数字の具体的明示(約80%):** 「ダンス歴12年」「4ヶ国語」など
6. **ダッシュ(――)による余韻演出(約30%)**
7. **「前世」という業界用語(約75%):** 芸能活動歴を「前世」と呼ぶ
8. **応援口調の統一:** 全記事がファン目線・応援トーン。批判的記述なし。

## 11. 視覚デザイン・HTMLスタイル(SWELLテーマ)

### キャプションボックス(swell-block-capbox)

```html
<!-- 小タイトル型: プロフィール表・経歴表・まとめに使用 -->
<div class="swell-block-capbox cap_box is-style-small_ttl">
  <div class="cap_box_ttl">プロフィール</div>
  <div class="cap_box_content">(内容)</div>
</div>

<!-- ボーダー上タイトル型: スクール・番組の補足説明に使用 -->
<div class="swell-block-capbox cap_box is-style-onborder_ttl">
  <div class="cap_box_ttl">JOY DANCE JAPANとは?</div>
  <div class="cap_box_content">(内容)</div>
</div>
```

### テキストマーカー(swl-marker) — 記事ごとに色を統一

| クラス名 | 色 | 使用例 |
|---|---|---|
| `swl-marker mark_orange` | オレンジ | 人名・番組名・グループ名・日付 |
| `swl-marker mark_green` | 緑 | 人名・出身・言語・特徴キーワード |
| `swl-marker mark_yellow` | 黄色 | 重要キーワード |
| `swl-marker mark_blue` | 青 | 補足情報(例:「父親が韓国人」) |

1記事につき1〜2色に絞る。番組名・グループ名・固有名詞、重要な日付・年齢に使う。

### インデントボックス(SNSコメント・視聴者の声の引用)

```html
<p class="is-style-dent_box wp-block-paragraph">
  "視聴者コメントのテキスト"
</p>
```

### ✔ボーダーリスト(特徴・ロールモデルの列挙)

```html
<p class="has-border -border02 wp-block-paragraph">
  ✔ ダンスで魅せる(カイ)<br>
  ✔ 音楽やスタイルは攻める(NCT)
</p>
```

### 見出し・強調

```html
<h2 class="wp-block-heading">〇〇のwiki風プロフィール</h2>
<h3 class="wp-block-heading">基本プロフィール</h3>
```

`<strong>`で太字強調。`<span class="swl-fz u-fz-xs">`で小文字注釈、`<span class="swl-fz u-fz-l">`で大文字強調。SWELLテーマが左カラーボーダー・背景色などを自動スタイリングする。

## chomoand.com(TikTok/YouTube発インフルエンサー)向けの読み替え

このスキルは元々chomoand-1.com(オーディション番組の練習生)向けだが、chomoand.comの新方針([docs/chomoand-pivot.md](../../../docs/chomoand-pivot.md)参照)にも同じ型を流用する。以下の要素を読み替える:

- リード文の「番組名(正式名)」→「TikTok/YouTubeでの活動内容・バズったきっかけ(動画タイトル・投稿内容)」
- H3「前世は?」→「TikTok/YouTube以外の活動は?」(過去の芸能活動・別名義・以前のSNSアカウントの有無)
- H3「〇〇スクール出身」「〇〇番組出演」(時系列)→「投稿・配信を始めた時期」「バズったきっかけの投稿」「現在のフォロワー数・登録者数」
- プロフィール表の「所属」→「所属事務所(あれば)」または「主な活動プラットフォーム(TikTok/YouTube/Instagram)」
- MBTI・「まとめ」の締め(「今後の活躍が楽しみです」等)はそのまま使える
