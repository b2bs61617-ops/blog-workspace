# chomoand-4.blog 全44記事のアイキャッチ3行デザイン化(2026-09-19)

- `before.json`: 差し替え前の各記事の featured_media(元画像ID)・タイトル・スラッグ・ステータス
- `after.json`: 新しく作ったメディアID(記事ID → メディアID)
- `apply.py gen|upload|restore`: 画像生成 / アップロード+差し替え / 元に戻す
- 記事のタイトル・スラッグ・本文・ステータスは変更していない(featured_mediaのみ)。差し替え後にサーバーと照合して不一致0を確認済み。
- 新記事を足したら `apply.py` の `SPLITS` に「記事ID: 1行目|2行目|3行目」を追加するか、単発なら `tools/eyecatch_torahja.py --split` を使う。
- 色: タイトルにメンバー1人→そのメンバーカラー、グループ/なし/複数人→紫。`げんたに会いに大阪`は「げんた」=松田元太として青。
