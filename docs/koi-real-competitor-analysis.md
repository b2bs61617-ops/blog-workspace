# 恋愛リアリティ専門サイト 競合調査(2026-07-19)

chomoand.comの[koi-realスキル](../.claude/skills/koi-real/SKILL.md)強化のため、恋愛リアリティ番組の出演者wiki・まとめ記事を書いている上位3サイトの全記事タイトルをWordPress REST API経由で取得し、傾向を分析した。生データ(タイトル・URL・日付・カテゴリ)はローカルscratchpadに保存済み(このリポジトリには含めていない)。

## 記事タイプ(3サイト共通の4パターン)

### A. 出演者個別プロフィール記事(chomoandの主力と同じ型)
```
今日好き|りら(岡本莉來)の高校と中学はどこ？TikTokでダンス投稿が話題で交通安全スマイル大使の活動も気になる！（インチョン編）
シャッフルアイランド7のとおるは誰？堀江亨の年齢・身長・テニス経歴・インスタ
```

### B. 話数ごとのネタバレ・あらすじ・感想記事(chomoand未実施の型)
```
今日好きインチョン編【最終話】ネタバレあらすじと感想！追いかけるより追いかけたい？奇跡のカップルは現れる？
```
恋愛ふりーくすではこの型のキーワード出現数が圧倒的トップ(ネタバレ2,516件／感想2,362件／あらすじ2,074件)。放送中は毎話公開して継続的にPVを取る戦略。

### C. 放送後「その後」記事(koi-realのC型と同じ)
```
今日好き かなりのが別れた！？その後付き合ったの？今現在を調査！（河村叶翔・相場星音）
```

### D. メンバー一覧ハブ記事(koi-realのD型と同じ)
```
【シャッフルアイランド7】メンバー16名一覧｜年齢・職業・インスタ・SNSまとめ
```

## タイトルのフォーミュラ

3サイトほぼ共通の型:

```
【番組名/通称】名前（本名）+ は誰？/の高校はどこ？/のプロフィール + 属性(高校・身長・インスタ・経歴・SNS) + まとめ/を調査！ + （シーズン名）
```

疑問形で終わるタイトルが圧倒的多数。[docs/rules.md](rules.md)の既存ルール(疑問形・結論ファースト)・[trend-titleスキル](../.claude/skills/trend-title/SKILL.md)の左寄せの法則と方向性は一致している。詳細な型は[koi-realスキル](../.claude/skills/koi-real/SKILL.md)の「タイトルの型」節に反映済み。

## その他の気づき

- **「高校」特定の踏み込み度はサイトで差がある**(fstopics 810件で最も攻めている／teiban-navi 14件・hapinyan 1件で慎重)。chomoandの現行方針(断定せず「〜と推測されます」)は、はぴにゃん寄りの中間的な立ち位置で、プライバシーリスクとPVのバランスとして妥当。
- 定番ナビは恋リア専業ではなく芸能wiki全般のハブサイト。恋リアでは主に「メンバー一覧まとめ」(D型)中心で、個人深掘り(A型)はほぼやっていない。真の直接競合は恋愛ふりーくすとはぴにゃんブログ。
