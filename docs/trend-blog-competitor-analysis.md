## Minsu PRESSのタイトルフォーミュラ

```
【番組名/カテゴリタグ】+ 対象(人物・場所) + 疑問形(どこ？誰？なぜ？いつから？本当？) + ！+ 答えの核心を先出し
```

例:
- 【水ダウ】名探偵津田のロケ地はどこ？群馬県の旧秋元別邸で映画やドラマにも！
- 【画像】土居志央梨はどこのバレエ団に所属？法村友井バレエ団で15年間の経歴がすごい！
- アレン様のギャラは1本30万以上？年収は8000万で収入源にパトロンも！

仕掛け:
- **【画像】【動画】タグ**を疑問文の前に置きCTRを稼ぐ
- **疑問文＋断定文のセット**(「〜はどこ？」で検索意図に一致させつつ「〜で△△！」と答えを先出しして強調スニペット＋クリック欲求の両取り)
- **具体的な数字**(年齢・年数・金額)を必ず入れて信憑性を演出

既存のkoi-real/chomoandのタイトル方針(疑問形・結論ファースト、[docs/rules.md](rules.md))と方向性は一致。ロケ地・グルメ系は「番組名＋ロケ地」のような複合キーワードでボリュームは中小だが競合が薄く、後発でも上位を取りやすいジャンル。

## 内容選定の傾向

1. **露出直後の「これ誰」需要**: TV/Netflix出演直後の共演者・端役・練習生プロフィール。旬が短く先行者利益が取りやすい(koi-realの「発表直後が勝ち筋」方針と同じ考え方)。
2. **ロケ地・複合キーワード特化**: 「番組名＋ロケ地」「番組名＋グルメ店」。chomoandでは現状未実施のジャンル。
3. **私生活wiki型**: 家族構成・彼女彼氏・出身校・実家・年収。資産記事になりやすい。

## content-gap-researchでの使い方

- KO1KEYZ・恋リア関連は`https://minsuaptblog.com/wp-json/wp/v2/posts?search={人物名}`でchomoand-1.com/chomoand.comとのネタ被り・抜け漏れチェックに使う。
- ロケ地ジャンルへの新規参入を検討する際は、上記ロケ地系サイト群を薄さ判定の比較対象にする。
