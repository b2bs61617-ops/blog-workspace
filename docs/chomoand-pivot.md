# chomoand.com方針転換の検討(2026-07-06〜)

chomoand.com(トレンドブログ)を今の速報型からジャンル転換する相談が始まった記録。結論はまだ「方向性決定」までで、具体的な仕組み作りは別セッション行い。

## 現状分析(トモキから聞いた事実)

- chomoand.comは約2年運用しているが、書いても**そもそも順位が付かない記事がほとんど**。
- 順位が付く記事もまれにあるが、**競合が3記事程度しか書いていない薄いサイトに丸パクリされて1〜3日で順位外**になる、がほぼ確実に毎回発生する。
- 唯一安定して**全記事が上位表示され続けている**のは、chomoand-1(KO1KYEZ、コイキーズブログ)。中身は練習生の「wiki・学歴・家族構成」のみ。

## なぜ通常のトレンド記事は弱いのか

- 一般的なトレンドニュースは、公開直後からYahooニュース・ORICONなど大手メディアがドメインパワーで即座に埋めるため、個人ブログは最初から勝負にならない。
- 事故・事件・不倫のような速報は「Query Deserves Freshness(QDF)」でネタが出た瞬間に競合ゼロの空白期間が生まれ、薄い記事でも一時的に上位に来るが、これは大手メディアが名誉毀損リスク等で及び腰な間だけの現象。**不倫等の裏取り不足による名誉毀損リスク・AdSenseポリシー違反リスク**が高く、狙って攻めるジャンルとしては危険度が高いと判断(不採用)。

## なぜwiki・学歴系(KO1KYEZ型)は強いのか

1. **競合不在**: 練習生レベルの知名度だと大手メディアが書かないので、個人ブログ同士の戦いにすらならない。
2. **検索需要が持続する**: 速報ネタと違い、学歴・家族構成は番組・グループ人気が続く限り何ヶ月も検索され続ける。Googleが鮮度優先で判断する必要がなく、滞在時間・CTRでじっくり評価が固まる。
3. **コピーで後発が不利**: 具体的な固有情報(学歴・家族構成)は実際に調べないと書けないため、丸パクリしても「後追いの二番煎じ」扱いになりやすく、速報のような早いもの勝ちの入れ替わりが起きにくい。
4. **後から"公式"が出てこない**: 大手メディアが後追いで上書きしてくることがないので、一度上位を取ったら明け渡す相手がいない。

## 検討した転換先ジャンル(2026-07-06時点)

| ジャンル | 強み | リスク・弱み | 採否 |
|---|---|---|---|
| 若手お笑い芸人の学歴・経歴wiki | 競合薄・公人なのでプライバシーリスク低・大会が年間通じて複数ある | M-1等の大会シーズンに記事が偏りやすい | 候補として残った(不採用ではない) |
| オーディション番組全般への横展開 | KO1KYEZで実証済みの型をそのまま使える・立ち上げが早い | chomoand-1(koikeyz)と客層・ジャンルが被り共食いリスク | 見送り |
| **TikTok/YouTube発バズインフルエンサーの学歴・経歴wiki** | 市場規模が大きい・話題性が高い | 人の入れ替わりが速く記事の賞味期限が短い・既存の芸能メディアも参入し始めている | **採用(2026-07-06決定)** |
| Vtuber中の人(前世)wiki | 検索需要が非常に大きい | 「中の人特定」は事務所からの削除要請・名誉毀損・プライバシー侵害訴訟リスクが4案の中で最も高い | 見送り |

## 決定事項

**chomoand.comは「トレンド速報ブログ」から「TikTok/YouTube発バズインフルエンサーの学歴・経歴wiki」路線へ転換する方針で合意(2026-07-06)。**

- Why: トレンド速報は2年運用しても大半が順位不発 or 順位が付いても即座に競合コピーサイトに奪われる構造的弱点があり、時間をかけても改善しにくいと判断。一方でKO1KYEZ型(wiki・学歴・家族構成)は全記事が安定して上位表示されている実績があるため、同じ型をchomoand.comにも展開する。
- How to apply: chomoand.comの新規記事は「バズった人物そのもののニュース」ではなく「その人物の学歴・経歴・家族構成・本名」を深掘りする記事を軸にする。既存の[wiki-article](../.claude/skills/wiki-article/SKILL.md)・[gakureki-kazoku-kanojo](../.claude/skills/gakureki-kazoku-kanojo/SKILL.md)・[sns-research](../.claude/skills/sns-research/SKILL.md)スキルがそのまま使える見込み。
