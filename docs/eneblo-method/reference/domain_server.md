## サーバーとドメインとは？

サーバー＝土地
ドメイン＝住所

これってどういう事？

世界中には多くの企業サイトや専門サイト、オリジナルの独自サイトなどが存在しますよね？

それらを管理するためにはそのサイト固有の情報が必要です！

例えば、あなたの家には住所がありますよね。それはあなたが住んでいる固有の住所だと思います。サイトも同じで個別の住所を登録しなければいけないのです。

それがドメインと言われるものです！

自分のサイトの土地をサーバーと呼び、住所をドメインと呼んでいる！

この住所には独自ドメインと呼ばれる有料で利用できるものと、無料で利用できるものがあります。

これらの違いについて紹介していきます！

## 独自ドメインの特徴

独自ドメインは自分の家と同じです。有料であなたの独自ドメインを購入できます。

このサイトも独自ドメインで作られています！

https://hide000.net

私の場合はXserverと呼ばれるサーバー会社と契約して、独自ドメインを取得しました。

独自ドメインの主な特徴は？

【メリット】
①自分のサイトを資産化できる
②サイトをカスタマイズ可能
③最終的をSEO向上させて、サイトを育てることが出来る

【デメリット】
①月1000円ちょっとの費用が必要
②最初はサイトパワーが弱い
③収益化に時間が必要

## 無料ドメインの特徴

無料ドメインは部屋を借りるようなイメージですね。企業が準備している土地に自分の家を構えるようなものです。

具体的にはamebloやhatenablogで自分のサイトを立ち上げます。

その結果ドメイン名は下記のようになります。

https://ameblo.jp/○○○○
https://hatenablog.com/○○○○

無料ドメインの特徴は？

【メリット】
①無料で利用できる
②初期からある程度SEOが強い

【デメリット】
①規約が厳しくブログ削除のリスクあり
②サービスが終了するとブログが無くなる
③独自サイトに勝てなくなる
④資産にならない

## 無料ドメインと独自ドメインどっちがオススメ？

無料ドメインと独自ドメインどちらが良いのか・・・

私の見解としてはブログの進め方によって考え方が違います！

ブログで収益化するなら独自ドメイン！

独自ドメインは初期こそサイトパワーが弱いですが、最終的には無料ドメインよりSEO向上が見込めます。あなたが資産運営を目的としてサイトを立ち上げる場合は独自ドメインをオススメします！

しかし、もしサイトで日記のようなものを書きたいだけであれば、特別独自ドメインを取る必要もないと思います。

重要なのは収益化するかどうかの違いで判断して問題ないと思います！

ドメインを取得したい方はサーバー契約も必須となる為、こちらも一緒に確認ください。
