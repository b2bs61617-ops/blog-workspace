# 年間ネタカレンダー(2026-08-03作成)

毎年ほぼ同じ時期に同じ検索需要が発生する年次イベントをまとめたもの。[tv-research](../.claude/skills/tv-research/SKILL.md)が「番組表から旬な出演者を先に見つける」のと同じ発想で、**イベント本番を待たずに発表・開催のタイミングを先回りして仕込む**ためのカレンダー。[x-trend-article](../.claude/skills/x-trend-article/SKILL.md)のXトレンド監視(反応型)を補う、予定が読める攻め方。

新サイト(雑記トレンドブログ、2026-08立ち上げ中)のネタ探しの3本目の柱として使う(1本目=Xトレンド監視、2本目=番組表監視、3本目=このカレンダー)。

## 使い方

各イベントについて「発表・情報公開の目安時期」を過ぎたら検知して先に記事化し、「本番中の狙い所」は当日にすぐ更新できるようテンプレを事前に用意しておく。過去に実際に大きく当たったネタ(24時間マラソンの「今どこ」で7万PV等)は事例として残し、翌年以降の判断材料にする。

## 運用メモ

- このカレンダーは新サイト立ち上げに伴って作成した初版。実際に運営しながら「効いたイベント」「不発だったイベント」を追記していく。
- イベントごとの「発表の目安時期」が近づいたら能動的にWebSearch/公式SNSで発表を確認しにいく運用を想定(現時点では自動監視ツール化はしていない)。
- 24時間テレビのような「発表直後の窓は競合が速く埋める・本番中のリアルタイム実況が本命」というパターンは、他の年次特番にも当てはまりやすい一般則。
