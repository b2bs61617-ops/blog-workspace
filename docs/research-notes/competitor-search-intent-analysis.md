  3. 実際に起きていた事実(破局)を時系列で示し、デマではない部分の透明性を担保
  - **デマ検証記事はネガティブな検索ボリューム(死亡・干された等)を正面から拾いつつ、否定して安心させるという構成**が独自の型として確立している。恋リア以外でも(有名人の"消えた""干された"系)応用可能。

| 記事 | 文字数体感 | 薄さ/濃さのポイント |
|---|---|---|
| 引田天功の埋蔵金(18) | 8,000〜10,000字 | 視聴者の疑問をほぼ全て見出し化。トリビア系の理想形 |

| ラストノートロケ地(12) | 約1,500字 | 住所羅列のみ、ドラマ内の意味づけなし=**薄い実例** |
| ホットスポットロケ地(13) | 1,000字未満 | 1施設のみ、周辺情報なし=**薄い実例** |
| つば九郎の正体(20) | 1,500〜2,000字 | 一次情報が少ないジャンルの構造的な薄さ |

## 横断的パターン分析

### 1. 「今この話題を書く」と判断する共通シグナル

- **発表・放送直後の即時性**: 新メンバー発表、新シーズン配信開始、放送翌日の視聴率発表。空白期間の存在が先行者利益になる(koi-realと同じロジックが恋リア以外でも通用する)。
- **SNS上の言及急増・疑問の可視化**: 「〇〇って本当?」「なんで消えた?」といった具体的なつぶやきが一定量出た段階で記事化(緋咲一馬のあざ、ぱーてぃーちゃん信子の徳川家説、ゆあ死亡デマ)。
- **一次情報の新規発生**: YouTube配信での発言、SNS投稿、テレビ特番など、既存の噂に新しい"燃料"が投下されたタイミング(ラヴ上等カップルその後、引田天功埋蔵金)。
- **異例さ・逆説性そのもの**: 「結成2ヶ月でファンミ」「顔非公開のままグループ名発表」「初回視聴率低いのに総合視聴率高い」など、通常のパターンから外れた事象自体がフック。
- **既存の疑問(過去記事)の再燃**: 人物が別の理由で再注目された際に、過去からくすぶっていた検索ワード(アンチ・干された・消えた)を掘り起こす。

### 2. 検索意図の種類ごとの掘り方の違い

| 意図の種類 | 典型記事 | 掘り方の特徴 |
|---|---|---|
| 人物プロフィール(新規登場) | 玉置慶プロフィール | 「不明」で終わらせず周辺情報(学業両立の推測など)で埋める。SNSリンクは信頼性担保の必須要素 |
| 人物プロフィール(血縁・ずらし) | TUIDEソヨン、野村康太実家 | 本人単体の情報が薄くても、家族・血縁関係を軸に広げれば厚みが出る。「非公開」自体を戦略として分析するメタ視点も有効 |
| ロケ地・撮影地 | GIFT、名探偵津田 | 「どこ?」への回答だけでは薄い。ドラマ内での意味づけ+アクセス情報+訪問マナーまで書くと厚みが出る |
| イベント・番組情報 | KO1KEYZファンミ、ラヴ上等メンバー | FAQ形式で「まだ分かっていないこと」も含めて構造化するのが有効。ファンの実務ニーズ(チケット・グッズ・ルール)を拾う |
| 炎上・スキャンダル・噂 | 花乃まりあアンチ、こじるり消えた理由 | 断定を避け「~という声がある」「一次情報は見当たらない」と誠実に濁しつつ、要因を複数に分解して分析っぽく見せる |
| デマ・誤情報の否定 | ゆあ死亡デマ | 冒頭で即否定→デマ発生要因を構造化して説明→実際の事実(破局等)を時系列提示、の3層構成が型 |
| 番組考察・数字系 | 夫婦別姓刑事視聴率 | 一つの数字(視聴率)を多角的に解釈し直す(リアルタイムvs総合)ことで「実は」の逆張り記事にする |
| トリビア・都市伝説 | 引田天功埋蔵金、つば九郎正体 | 視聴者が持ちうる疑問を洗いざらい見出し化。一次情報(番組発言・ファンブック)への依存度が高く、情報源が薄いと記事も薄くなりやすい |

### 3. 「隙間」の見つけ方・ずらし戦略の実例

- **「不明」を逆手に取る**: TUIDEソヨンの記事は、プロフィールが非公開であること自体を「なぜ非公開なのか」という戦略分析に転換している。情報がないなら「情報がないこと」を記事にする発想。
- **数字の見せ方を変える**: 夫婦別姓刑事はリアルタイム視聴率(低い)と総合視聴率(高い)という2つの数字を対比させることで、「低視聴率なのになぜ注目される?」という一見矛盾したフックを作っている。
- **周辺人物・血縁への展開**: 本人の情報が薄くても、父親・母親・兄弟の経歴や家族エピソードまで広げれば厚みが出る(野村康太、TUIDEソヨンの三姉妹の物語)。
- **訪問実用情報への展開(ロケ地系)**: 「どこで撮影されたか」だけでなく「実際に行けるか」「アクセス方法」「マナー」まで書くことで、単なる情報記事から実用ガイドへ格上げしている。
- **デマ・誤情報の火消し役**: ネガティブワード(死亡・干された・消えた)の検索ボリュームをそのまま拾い、否定することで安心材料を提供する記事は、大手メディアが扱わない「隙間」そのもの。
- **番組視聴中のミクロな疑問の拾い上げ**: 「顔のあざ」のような、番組を見ている最中にふと気になった細部への疑問は、公式情報には絶対出てこない領域であり、SNSの声を引用元にすることで記事として成立させている。

## 雑記トレンドブログへの示唆(要点)

1. **速報 → 後埋めの二段構え**が使える(fstopics方式)。放送直後は骨組みだけ公開し、後から加筆すれば「最速」と「厚み」を両立できる。
2. **ロケ地・イベント系は「情報量の物量」がそのまま差別化になる**ジャンル。住所を書くだけでは薄い(filminglocation-star.com)、意味づけ+実用情報(アクセス・マナー)まで書けば濃い(dramarelle.com)。
3. **「不明」「非公開」は逆に記事化のフック**になりうる。なぜ非公開なのか、なぜ分からないのかを分析する視点を持てば、情報が少なくても記事は書ける。
4. **デマ・炎上・数字の逆張りは、大手が扱わない隙間**。ネガティブ検索ワードを正面から拾い、誠実に否定/分析する構成は独自性が出しやすい。
