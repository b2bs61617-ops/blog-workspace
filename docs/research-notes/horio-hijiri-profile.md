## 「世が世なら!!!」加入まわり

- グループ: 2021年10月1日結成(当初4人→同年12月に6人)、つばさ男子プロダクション所属。コンセプトは「本気系おふざけ集団」。TikTok/Instagram/YouTube軸、アー写で変顔。
- リリース実績: CDシングル4枚 / 配信シングル9曲 / EP3枚 / フルアルバム1枚。2023年アルバム『俺ならやれそうじゃん？』。
- 2026年6月14日: 笠松正斗・橋爪優真が脱退、オリジナル体制終了 → 新体制へ。
- 新体制の既存メンバー(公式プロフィール掲載): 大谷篤行(2005/1/17・神奈川・167.5cm) / 添田陵輔(2003/11/13・埼玉・183cm) / 中山清太郎(2005/1/22・高知・178.5cm) / 内藤五胤(2002/7/30・埼玉・175cm)。堀尾を含めまず5人掲載、残り新メンバー3人は順次発表予定。
- お披露目: 2026年9月4日(木) 池袋・サンシャインシティ噴水広場「新体制お披露目フリーライブ」(開場18:45・入場無料)。
- 2026年10月〜: 新体制初の全国5大都市ツアー(日程・会場・チケット未発表)。
