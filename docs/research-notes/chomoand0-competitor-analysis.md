## 2. サイトごとの記事タイトルサンプルと分析

**記事タイプの傾向**: 1人のタレントを「整形」「ビジュアル遍歴」「サングラス」「脱退理由」「タトゥー」「アクセサリー(ネックレス/ピアス/指輪/腕時計)」「若い頃」「私服ファッション」「愛犬」「髪型」「自宅」「年収」など10〜15本の極小トピックに徹底的に分解する"超ずらし記事"型。1人あたりの記事数が非常に多い(赤西仁だけで9本確認)。学歴・家族構成・熱愛だけでなく、ファッション・美容(整形/髭/メイク)・持ち物(アクセサリー/愛車)まで扱うのが特徴。

**タイトルの型**: 「[人物名]の[トピックA]は[結論]！[トピックB]も紹介」「[人物名]、[トピックA]。[トピックB]＆[トピックC]」のように「＆」で2〜3個の小トピックを1タイトルに連結するのが定番。疑問形は一部(「〜はホント？」)のみで、断定文+補足の形が多い。人物名は必ずタイトル先頭。

**記事タイプの傾向**: 学歴・出身校のみに特化した縦型サイト。旧ジャニーズ／STARTOに限らず声優・アナウンサー・女優・K-POPまで扱う「学歴専門データベース」で、対象人物の網羅性が非常に高い(1テーマに絞って幅広い人物をカバーする横展開型)。

**タイトルの型**: 「[人物名]の学歴と経歴｜出身は[学校名]！大学や中学校の偏差値と[フック(留年・中退・かわいい画像・意外なエピソード)]」がほぼ100%固定のテンプレート。パイプ「｜」区切りで(1)学校名を即座に開示、(2)「偏差値」というキーワードを必ず入れて検索意図(偏差値どのくらい？という比較欲求)を刺す、(3)最後に一言フックを添える三段構成。疑問形はほぼ使わず「学歴と経歴」という言葉が毎回先頭のフォーマット句として固定されている。

**タイトルの型**: 「[本人]と[相手]が付き合っていた／熱愛はホント？[煽り文句・匂わせ根拠]」の2人名+疑問形が基本形。もしくは「[本人]の歴代彼女は[N]人！[結論フック]」という人数を明示する型。数字(何人、何％)を使って好奇心を煽るのが特徴的で、他2サイトより煽り度・下世話度が強い(「アパホテル密会」「ナンパ」など)。

## 3. 3サイト比較・共通パターンと差別化ポイント

**共通点**:
- 3サイトとも**人物名(検索キーワード)を必ずタイトル先頭に置く**「左寄せの法則」がこのジャンルでも成立している。chomoand.comの知見がそのまま転用できる。
- いずれも1人の人物について複数記事に分割する「ずらし記事」戦略を採用(特にasuneta.comが極端)。
- WordPressベースで、REST API(`/wp-json/wp/v2/posts`)が有効な場合が多い(yumeijinhensachi.com・fiatcaffe.jpは素直に取得可、asuneta.comはCDNキャッシュにより実質使えず、カテゴリアーカイブページの直接WebFetchが必要だった)。

**差別化ポイント(3サイトのポジショニングの違い)**:
- **asuneta.com**: 「広く浅く、1人を何本にも分解する」総合芸能ブログ。旧ジャニーズ専業ではない分、勝負ジャンルが分散している。
- **yumeijinhensachi.com**: 「1テーマ(学歴)を、対象人物を広げて量産する」垂直特化型。学歴クエリではほぼ確実に上位に出てくる。
- **fiatcaffe.jp**: 「1テーマ(熱愛・彼女)を、旧ジャニーズ限定で総当たり量産する」垂直特化型。サイト名からしてジャニーズ専業を公言しており、chomoand-0と最も直接競合するポジション。

**「YouTube動画発の記事」競合の有無**: 「手越祐也 現在 YouTube」「Snow Man 向井康二 YouTube」「亀梨和也 YouTube動画」の3クエリで検索した限り、上位はいずれも公式YouTube動画・公式X・Wikipediaで占められ、上記3サイトを含め個人ブログがYouTube動画のロケ地・ファッション・食べ物ネタを記事化して上位表示している例は見当たらなかった。YouTube発の日常ネタを深掘りする専業ブログは今回の調査範囲では確認できず、空白地帯の可能性がある。

## 4. chomoand-0向けの示唆

1. 学歴(yumeijinhensachi.com/ibrado.com)と熱愛(fiatcaffe.jp/niowase.com)はすでに専業サイトが厚く量産しており、真正面から量で勝負するのは分が悪い。狙うなら「脱退・炎上・現在の活動」など、asuneta.com的な広く浅い総合ブログしか押さえていない、人物単位で深掘りが浅いニッチを探すのが得策。
2. タイトル設計は3サイト共通の「人物名を先頭に置く」「数字(歴代彼女は◯人、匂わせ◯個)で好奇心を煽る」「学歴なら『学歴と経歴｜出身は◯◯！偏差値』の三段テンプレート」をそのまま踏襲でき、chomoand.comの「左寄せの法則」がジャニオタ市場でも通用することが確認できた。
3. **YouTube動画発ネタ(ロケ地・ファッション・食べ物などの日常ネタ)は今回調べた範囲では専業の強い競合が見当たらず、chomoand-0が最近始めたYouTube監視ツール戦略はブルーオーシャンの可能性が高い**。ただし対象人数・検索ボリュームが学歴/熱愛より小さい可能性があるため、まずは数記事出して検索順位・流入を検証するのが良い。
4. asuneta.comの「1人を10本以上に分解する」手法(整形/アクセサリー/私服/愛犬/自宅など)は、既存の学歴・彼女・家族構成の3本柱に加えて、chomoand-0でも人物ごとの記事本数を増やす追加ネタ源として応用可能。
