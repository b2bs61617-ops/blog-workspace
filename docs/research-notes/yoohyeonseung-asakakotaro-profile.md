# ユ・ヒョンスン / 浅香孝太郎 プロフィールメモ

2026-09-28に「ヒョンスン＆孝太郎の京都Vlog聖地」記事(chomoand-1.com 下書き JP13897 / KR13901 / EN13902)を書いたときに調べたスペックとVlogで分かったこと。今後この2人の記事を書くときのリサーチ時間を短くするために残す。

2人とも『PRODUCE 101 JAPAN 新世界(日プ4)』に出ていた練習生で、KO1KEYZのデビューメンバー12人には入っていない。どちらも韓国のボーイズグループPICKUS(ピカス)の元メンバーで、同じグループにはYURA(安部結蘭)もいた。

## 共通の経歴

- 2023年8月: 韓国のオーディション番組「Fan Pick」(MBC M)に出演し、デビューメンバーに選ばれる
- 2024年4月23日: PICKUSのメンバーとしてシングル「Little Prince」でデビュー(所属は韓国TNKエンターテインメント)。その後、ファンへの告知がないまま活動を終えたとみられる
- 2025年9月: 韓国のオーディション番組「PROJECT 7(プジェ)」に出演
- 2026年春: 日プ新世界(日プ4)に出演
