## ①「Claude Codeでアフィリエイト稼いでいる」は本当か

**結論: 大部分は検証不能な誇張・情報商材の宣伝文句。使い方自体は事実だが、儲かっているかは別問題。**

- X検索で「月100万稼いだ」「月商1,885万のアフィカス」「累計2億稼いだ」等、高額な自己申告が大量にヒットする(465件中の多くがこの種の投稿)
- 実際に上位ヒットした記事2本(`thchblogsite.xsrv.jp`の「月5万円稼いだ正直な話」、`note.com/takeuchigoro`の「Claude Code×AI副業」)をWebFetchで精査した結果、**どちらも収益の証拠(ASP管理画面のスクショ、実サイトURL、PV数)は一切示されていない**。かつ両記事とも¥980〜¥1,980のnote販売・LINE誘導・有料記事(¥1,480)への導線として設計されている
- X上には自己批判的な投稿も複数存在し、「【暴露】話題のClaude Code使っても**99%は収益化に失敗**します」「【悲報】...**98%は収益化に失敗**」といった投稿が見つかった(収集データの2026/04/11付近)。これが実態に近いと推測される
- 実態としては「Claude Codeというバズワードを使って"稼げる系"のnote/Brain/コンサルを売る」という**情報商材アフィリエイト**のマーケティング手法が主流になっている
- 一方、語られている**技術的な使い方自体は妥当**で誇張ではない。頻出パターン:
  - WordPress記事の自動量産(キーワードリサーチ→アウトライン→執筆→投稿)
  - X/Threads/Instagramアカウントの自動運用
  - ASP案件のリサーチ・比較、LP作成
  - 動画台本・ショート動画の自動生成
  - これはchomoand.comで実際にやっている運用方針と方向性が同じ

## ② アフィリエイトで稼ぐために必要な準備

- ASP登録(A8.net、もしもアフィリエイト、バリューコマース、楽天アフィリエイト等)。無料・複数登録が基本(同じ案件でも報酬額が異なることがある)
- 媒体の用意(ブログ/note/SNS/YouTube)。ブログならドメイン・サーバー・WordPress
- ジャンル(ニッチ)選定
- 特商法表記・アフィリエイト開示文などのコンプライアンス対応
- キーワードリサーチ(検索意図に応える記事設計)
- **継続する運用体制**。数百円→数万円レベルまで育つのに数年単位が普通

## ③ 既存の成功事例に共通するパターン

第三者検証可能な実例(「ミニ四駆改造アカデミー」等、収益推移を公開しているブログ)を調べた結果:

- **ニッチへの特化**(対象読者を明確に絞る。「速いマシンを作りたい人」のように)
- **SEO軸**。SNSは副次的、と明言する成功者が多い
- **集客記事→収益記事への内部リンク設計**(トップページのバナー導線含む)
- **収益成長は地道**: 2017年月138円 → 2018年月1万円 → 2020年月10万円 → 2021年年間売上1,000万円、という4年がかりの推移が実例として確認できた
- YouTubeでは「視聴者との信頼関係」が成約率を左右。デメリットも正直に言う方が信頼が増す、という点が複数ソースで共通

→ 勝ちパターンは「ニッチ×継続×信頼」であり、ツール(Claude Codeの有無)とは別軸。

## ④ Claude Codeの利点と売上への貢献・限界

**貢献できる部分:**
- 記事・SNS投稿の大量生産と投稿作業の自動化(chomoand.com運用そのものが実例)
- Xiyのような自作ツールでの競合調査・SNS分析の自動化
- `tools/affiliate_linker.py`のようなアフィリエイトリンク自動挿入ツールをコードで自作できる
- WordPress投稿・アイキャッチ生成・公開までのパイプライン化

**限界・リスク:**
- 売上を最終的に決めるのは「ニッチ選定」「読者の信頼」「検索意図への回答度」であり、Claude Codeは**制作コストを下げるだけ**
- 量産に偏ると「薄い記事」になりやすく、Googleのスパム判定で淘汰されるリスクがある(このリポジトリでも過去にラヴ上等2の薄い記事76本を1人1記事に統合した経緯があり、CLAUDE.mdの「薄い記事は書かない」ルールはこのリスクへの対策と整合する)
