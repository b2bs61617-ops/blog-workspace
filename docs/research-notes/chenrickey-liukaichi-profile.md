# チェン・リッキー / リュウ・カイチ プロフィールメモ

2026-07-18に「リッキーとカイチ先生のインスタライブ」記事(`rickey-kaichi-instalive`、chomoand-1.com ID:10583)執筆時にproduce101.jp公式サイトから取得したスペック。以後この2人が絡む記事のリサーチ時間短縮のため保存。

両者とも『PRODUCE 101 JAPAN 新世界(日プ4)』の元練習生(KO1KEYZ正式デビュー12人には含まれない)。

## チェン・リッキー(CHEN RICKEY)

- 生年月日: 2006年2月9日
- 出身地: 台湾・新竹(ホーチュー)
- 身長: 178cm
- 趣味: 筋トレ、歌、ダンス
- 特技: 人体ゴマ
- MBTI: ENFJ
- キーワード: 「皆を明るく照らす太陽」
- 経歴: 2024年に中国・韓国合同のボーイズグループ育成番組「SCOOL」にデビュー候補生として出演(4次で脱落)。『日プ新世界』では国内投票1位を獲得する人気ぶり。
- **台湾在住**(日本には来日する側)。日本語はまだ得意ではなく、公の場ではリュウ・カイチが通訳役を務めることが多い。
- wiki記事: https://chomoand-1.com/chenrickey_wiki-1494

## リュウ・カイチ(LIU KAICHI)/ 通称「カイチ先生」

- 生年月日: 2004年2月13日
- 出身地: **愛知県**(日本在住。来日するのはリッキー側であってカイチ側ではない点に注意)
- 身長: 184cm
- 趣味: アニメ、楽器
- 特技: 「自分の良いところをいっぱい言える所」
- MBTI: ENFP
- キーワード: 楽観主義者
- 番組内外でリッキーの日本語サポート・通訳役を務めることが多く、その面倒見の良さから「カイチ先生」と呼ばれている。
- wiki記事: https://chomoand-1.com/wiki-liu-kaichi-1041
