# 24時間調査用PCの計画（2026-11-17〜 検討中）

ユカの相談から始まった計画。マツ（Claude Code）を24時間動かして、ネット調査を自動で続けたい。

## 決まったこと

- **使うのは、家にある使っていないPC**（ユカいわく「そこそこ性能もいい」）。今後はそのPCからマツを使って作業する
- 機種・OS（Mac / Windows）はまだ聞いていない → 次のセッションで最初に確認する

## 検討して見送ったもの

| 候補 | 見送った理由 |
|---|---|
| NAS（Buffalo LinkStation LS520D0202G） | CPUが小さいARM系でメモリ1GB。Dockerなど追加アプリも公式に使えない。Xiyのブラウザ調査は重くて動かない。改造は保証切れ・データ破損のおそれがあるので非推奨 |
| クラウドの定期実行（/schedule） | 機械はいらないが、Xにログインして調べる作業（Xiy）が苦手 |
| 中古Mac mini / Raspberry Pi 5 | 余っているPCがあるので買わなくてよくなった（余りPCで問題が出たら、Mac miniが第一候補） |

## そのPCで守ること（ノートPCの場合）

1. **充電を80%で止める**設定にする（ずっと充電したままだとバッテリーがふくらむおそれ）
2. **ふたを開けたまま**、風通しのいい場所に置く
3. **スリープしない**設定にする

デスクトップ型なら 3 だけでよい。

## セットアップの流れ

1. [setup-new-pc.md](setup-new-pc.md) の手順で、Git・gh・Claude Code・リポジトリ・.env（Googleドライブがマスター）を用意する
2. XiyのためにXへログインし直す
3. 動作確認として、まず手動で1回調査を回す
4. 問題なければ「1日数回」の定期実行から始める（いきなり24時間連続にはしない）

## 注意

- **AIの利用枠**: 24時間ずっと動かすとClaudeのプランの使用上限にすぐ届く。時間を決めて動かす
- **bot判定**: 同じ時間に何度もXへアクセスすると判定されやすい。間隔をあけ、時刻を少しずらす
- **鍵の管理**: .envの鍵をそのPCに置く。リモート操作用にポート開放などでネットに公開しない
