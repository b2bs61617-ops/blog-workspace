# mapshot/ — 地図スクショの置き場所

トモキが自分のブラウザで開いた Google マップ(@YSB_DANCHO の位置共有リンクなど)の
**スクリーンショット画像をここに保存する**フォルダ。

- トラッカーは10分ごとに、このフォルダの**いちばん新しい画像**を Gemini Vision で読み、
  「中心付近の地名」を現在地の手がかりにする。
- 画像の更新時刻が **20分より古い**と「古い情報」として使わない(`config.json` の
  `mapshot_max_age_minutes`)。だいたい10〜15分おきに撮り直して上書き保存すると良い。
- ファイル名は何でもよい(`map.png` を上書きし続ける運用が楽)。png / jpg / webp 対応。
- 画像はGit管理外(この README 以外)。古いスクショは溜まっても新しい1枚しか見ないので
  気が向いたら消せばよい。

## 撮り方(Windows)

1. ブラウザで位置共有リンクを開く(ログイン済みなら現在地が正しく出る)
2. `Win + Shift + S` で地図部分を範囲選択 → クリップボードにコピー
3. ペイントなどに貼り付けて `tools/marathon-tracker/mapshot/map.png` に保存
   (または Snipping Tool の「名前を付けて保存」で直接ここへ)

地図が読めない/古いときは、このソースは自動でスキップされる(他ソースで動作継続)。
