# サジェスト穴場ファインダー

「名前 + あいうえお」のGoogleサジェストを集めて、競合の少ないキーワードとタイトル案を一覧にするツール。
マツ(Claude)のトークンは使わない。費用は0円(Gemini無料枠のみ)。

## 使い方

- **いちばん簡単**: `run.bat` をダブルクリック → 名前を入力 → 終わるとレポートがブラウザで開く
- コマンドの場合:
  ```
  python tools/suggest-finder/suggest_finder.py "松倉海斗"
  python tools/suggest-finder/suggest_finder.py "松倉海斗" --max 50       # 競合チェックは上位50件だけ(約5分)
  python tools/suggest-finder/suggest_finder.py "松倉海斗" --suggest-only # サジェスト一覧だけ(約1分)
  python tools/suggest-finder/suggest_finder.py "松倉海斗" --no-ai        # タイトル案を作らない
  ```
- 結果: `out/名前_日時.html`(見る用。◎だけ表示などの絞り込みあり) と `.csv`(Excel用)

## チームで使うとき(トモキ・ユカ・オシリ)

- GitHub経由で全員のPCに配られる。Claude Codeを起動すれば自動で `git pull` されて届く
- 各PCの `blog-workspace	ools\suggest-finderun.bat` をダブルクリックするだけ
- 初回だけ、足りない部品(requests / playwright / google-genai)を自動で入れるので数分かかる
- タイトル案には `.env` の `GEMINI_API_KEY` を使う(Googleドライブから自動コピーされる)。無くてもタイトル案なしで動く
- マツに「〇〇でサジェスト調べて」と頼んでもOK(マツがこのツールを動かす)
- 結果ファイルは各PCの `out/` に保存され、共有はされない。見せたいときはHTMLファイルを送る

## 中でやっていること

1. Googleサジェストを「名前 」「名前 あ〜ん」「名前 a〜z」の73パターンで取得(1人あたり数百件)
2. 各キーワードを **Yahoo!検索**(中身はGoogleと同じ)で上位10件チェック。Googleを直接見るとCAPTCHAで止められるため
3. 上位10件のタイトルを見て判定
   - 完全一致(タイトルに名前もサジェスト語も入っている)ブログ・個人サイト=1点、大手メディア・公式=2点
   - 部分一致(サジェスト語だけ入っている)=0.5点
   - Q&A(知恵袋など)・SNSは「ちゃんとした答え記事が無い」サインなので点数に入れない
   - **◎穴場 1点未満 / ○狙える 3点未満 / ×激戦 3点以上**
   - 自分のサイト(.env の WP_*_URL)が上位にいたら「自サイト」として表示
4. ◎と○のキーワードに、Gemini(tools/ai_hub.py経由)でタイトル案を3つずつ

## 注意

- 全件チェックは時間がかかる(425件なら約45分)。Yahoo!のブロックを避けるため1件ずつ3.5〜6.5秒あけている
- 競合チェックの結果は `cache/` に7日間保存。途中で止めても、再実行すれば続きから進む
- 判定は「タイトルに語句が入っているか」で見た目安。炎上などデリケートな話題は◎でも記事にするか要判断
- タイトル案はGeminiの下書き。事実と違う言い回し(例: 年齢に合わない表現)が混ざるので必ず見直す
- サジェストやYahoo!の画面構造が変わると取れなくなる。そのときは `YAHOO_ORGANIC_SELECTOR` を直す
